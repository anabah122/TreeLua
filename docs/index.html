TreeLua

Local documentation for TreeEngine — a Lua port of the three.js API for LÖVE. The structure mirrors threejs.org/docs: categories on the left, and on every class page a Constructor, Properties and Methods section, plus a "Differences from three.js" block wherever behaviour or signature diverged.

How to read this reference

  • Methods are called with :, and the object is passed as the first argument — three.js statics (e.g. AnimationClip.findByName) are methods here too.
  • Where a three.js name was already taken by an older immutable method on the engine, the mutating version carries a suffix: addSelf, subSelf, normalizeSelf, lerpSelf, minSelf/maxSelf, clampSelf, floorSelf/ceilSelf/roundSelf, transposeSelf. Everything else keeps its three.js spelling.
  • The Differences from three.js block on a class page is what to watch for when carrying knowledge over from the original docs: a different signature, reduced functionality, or a different default.

Quick start

local TL = require "TreeEngine"

local scene    = TL.Scene:new()
local camera   = TL.PerspectiveCamera:new(60, w / h, 0.1, 1000)
local renderer = TL.WebGLRenderer:new()

local gltf = TL.GLTFLoader:new():load("assets/model/model3dtest.glb")
scene:add(gltf.scene)

local mixer = TL.AnimationMixer:new(gltf.scene)
mixer:clipAction(gltf.animations[1]):play()

function love.update(dt) mixer:update(dt) end
function love.draw()     renderer:render(scene, camera) end

Internals

TL.internal exposes the importer layer (importer.common, importer.gltf, importer.dae, importer.obj) for anything the facade above doesn't cover. Its shape is not part of the stable API and is deliberately not documented here class-by-class — read the source under importer/ directly if you need it.

Limitations compared to three.js

  • The shader takes one directional light plus an ambient term — multiple directional lights are not yet supported.
  • No environment map / IBL, so reflections have nothing to reflect.
  • Skeletons are capped at 128 bones (MAX_BONES in the shader).

TreeLua

Локальная справка по TreeEngine — Lua-порту API three.js для LÖVE. Структура повторяет threejs.org/docs: слева категории классов, на странице каждого класса — разделы Constructor, Properties и Methods, а также блок «Differences from three.js» там, где поведение или сигнатура разошлись.

Как читать эту справку

  • Методы вызываются через :, и объект передаётся первым аргументом — статики three.js (например AnimationClip.findByName) здесь тоже методы.
  • Там, где three.js-имя уже было занято старым immutable-методом движка, мутирующая версия получает суффикс: addSelf, subSelf, normalizeSelf, lerpSelf, minSelf/maxSelf, clampSelf, floorSelf/ceilSelf/roundSelf, transposeSelf. Остальное сохраняет написание three.js.
  • Блок Differences from three.js на странице класса — это то, на что стоит обратить внимание при переносе знаний из оригинальной документации: другая сигнатура, урезанный функционал, иное поведение по умолчанию.

Internals

TL.internal открывает доступ к слою импортёров (importer.common, importer.gltf, importer.dae, importer.obj) для всего, что не покрыто фасадом выше. Его форма не является частью стабильного API и намеренно не документируется здесь по классам — если нужно, читайте исходники напрямую в importer/.

Ограничения по сравнению с three.js

  • Шейдер берёт один directional light плюс ambient-составляющую — несколько направленных источников пока не поддержаны.
  • Нет environment map / IBL, поэтому отражениям нечего отражать.
  • Скелеты ограничены 128 костями (MAX_BONES в шейдере).
