Object3D

Base class for objects in the scene graph. Holds a transform (position / quaternion / scale, kept in sync with .rotation), parent/child links, and the machinery that bakes the transform into matrix and matrixWorld. Group, Mesh, Scene and the cameras all extend it.

Differences from three.js

  • No property setters. three.js keeps .rotation and .quaternion in lockstep through JS property setters fired on every write. Lua has no such hook, so instead the engine reconciles them lazily in updateMatrix(): whichever of the two was written since the last sync wins (the euler wins if both changed). This means a raw write to .rotation.x is not reflected in .quaternion until the next matrix update — call :updateMatrix() directly if you need it sooner.
  • extend(typeName) is TreeLua's subclassing hook (used by Group, Mesh, Scene, the cameras) and has no three.js equivalent.
  • castShadow/receiveShadow are stored for API compatibility but not read by WebGLRenderer — there is no shadow mapping.

Object3D

Differences from three.js

  • Нет property-сеттеров. three.js держит .rotation и .quaternion синхронными через JS property-сеттеры, срабатывающие на каждую запись. В Lua такого хука нет, поэтому движок сверяет их лениво в updateMatrix(): побеждает то поле, что было изменено с последней синхронизации (при изменении обоих — побеждает euler). Это значит, что сырая запись в .rotation.x не отражается в .quaternion до следующего обновления матрицы — вызовите :updateMatrix() напрямую, если нужно раньше.
  • extend(typeName) — хук наследования TreeLua (используется Group, Mesh, Scene, камерами) и не имеет аналога в three.js.
  • castShadow/receiveShadow хранятся для совместимости API, но не читаются WebGLRenderer — карт теней в движке нет.
