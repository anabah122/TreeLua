TreeLua / Core

Group

An Object3D that exists only to hold children. Behaviourally identical to Object3D — the separate type is what lets callers (and the renderer) tell "this is a container" apart from "this is a thing that happens to have children".

Constructor

Group()

Creates a new Group. Extends Object3D and inherits its full API (transform, hierarchy, traversal, matrix update, clone/copy).

Properties

No properties of its own — inherits all of Object3D's (position, quaternion, scale, children, visible, ...).

Methods

.isGroup()

Returns true. Type-check facade over three.js's .isGroup flag.

All other methods come from Object3D — see that page for .add, .remove, .traverse, .updateMatrixWorld, .clone, and the rest.

TreeLua / Core

Group

Это Object3D, существующий только для того, чтобы содержать детей. По поведению идентичен Object3D — отдельный тип нужен лишь для того, чтобы вызывающий код (и рендерер) мог отличить "это контейнер" от "это объект, у которого просто есть дети".

Constructor

Group()

Создаёт новый Group. Наследует Object3D и получает весь его API (трансформ, иерархия, обход, обновление матрицы, clone/copy).

Properties

Собственных свойств нет — наследует все свойства Object3D (position, quaternion, scale, children, visible, ...).

Methods

.isGroup()

Возвращает true. Фасад проверки типа поверх флага three.js .isGroup.

Все остальные методы приходят из Object3D — см. эту страницу для .add, .remove, .traverse, .updateMatrixWorld, .clone и остального.
