PerspectiveCamera

Extends Camera, inherits its API. A camera with perspective projection, matching a real-world lens.

local camera = PerspectiveCamera:new(60, w / h, 0.1, 1000)
camera.position:set(0, 1.2, 3.5)
camera:lookAt(0, 1, 0)

Constructor

PerspectiveCamera(fov, aspect, near, far)

fov defaults to 50 and is in degrees — the one place this engine's radians-everywhere rule is broken on purpose, to match every three.js example. It is converted to radians when the projection matrix is built. aspect defaults to 1, near to 0.1, far to 2000. Builds the projection matrix immediately.

Returns true.

Recomputes projectionMatrix from fov, aspect, near, far, and zoom. Call after changing any of them.

.setFocalLength(focalLength)

Sets .fov to match a real lens's focal length, given filmGauge. Kept because three.js examples use it.

TreeLua / Cameras

PerspectiveCamera

Наследует Camera, наследует её API. Камера с перспективной проекцией, соответствующей реальному объективу.

local camera = PerspectiveCamera:new(60, w / h, 0.1, 1000)
camera.position:set(0, 1.2, 3.5)
camera:lookAt(0, 1, 0)

Constructor

PerspectiveCamera(fov, aspect, near, far)

fov по умолчанию 50 и указывается в градусах — единственное место, где правило движка «всюду радианы» намеренно нарушено, чтобы соответствовать каждому примеру three.js. Значение конвертируется в радианы при построении матрицы проекции. aspect по умолчанию 1, near — 0.1, far — 2000. Строит матрицу проекции немедленно.

Methods

.isPerspectiveCamera()

Возвращает true.

.updateProjectionMatrix()

Пересчитывает projectionMatrix из fov, aspect, near, far и zoom. Вызывайте после изменения любого из них.

.setFocalLength(focalLength)

Устанавливает .fov в соответствии с фокусным расстоянием реального объектива, с учётом filmGauge. Сохранён, поскольку используется в примерах three.js.

.getFocalLength()

.getFilmWidth()

.getFilmHeight()

.getEffectiveFOV()

Вертикальный FOV после применения zoom.

.setAspect(aspect)

Устанавливает .aspect и вызывает updateProjectionMatrix() только если значение действительно изменилось. Удобный метод, который рендерер вызывает при изменении размера окна; не имеет аналога в three.js.
