Box3

An axis-aligned bounding box, defined by min and max corners. Mutating throughout, like the rest of the three.js-facing math surface. An empty box has min = (+inf, +inf, +inf) and max = (-inf, -inf, -inf), so a fresh box grows correctly under expandByPoint with no separate empty flag to keep in sync.

Constructor

Box3( min, max )

min, max — Vector3s, cloned in. Default to an empty box.

Properties

.expandByPoint( point )

Expands this box to include point, in place. Returns self.

.expandByScalar( scalar )

Expands min outward and max outward by scalar on every axis. Returns self.

.expandByVector( v )

Expands min outward and max outward by v's components. Returns self.

.union( box )

Expands this box to also contain box, in place. Returns self.

.containsPoint( point )

Returns true if point lies within this box (inclusive).

.containsBox( box )

Returns true if box lies entirely within this box.

.intersectsBox( box )

Returns true if this box and box overlap.

.clampPoint( point, target )

Writes point clamped to lie within this box into target and returns it.

.distanceToPoint( point )

Returns the distance from point to the nearest point of this box (0 if point is inside).

.setFromPoints( points )

Resets this box, then expands it to cover every point in the array. Returns self.

.setFromVertices( vertices )

Builds the box from an array of raw vertex tables shaped {x, y, z, ...}, as used by geometry generators and importers. Returns self.

.setFromObject( object )

Computes the world-space bounds of object and everything beneath it. Every corner of each mesh's local bounding box is transformed individually (rather than transforming the box's min/max directly), since a rotated box's transformed extrema are not the extrema of its transformed corners. Returns self.

.equals( box )

Returns true if this box and box have equal min and max.

Box3

Осепараллельный ограничивающий параллелепипед (AABB), заданный угловыми точками min и max. Изменяется на месте (мутирует), как и весь остальной математический слой, обращённый к API three.js. Пустой box имеет min = (+inf, +inf, +inf) и max = (-inf, -inf, -inf), поэтому свежесозданный box корректно растёт под expandByPoint без отдельного флага "пустой", который нужно было бы синхронизировать.

Constructor

Box3( min, max )

min, max — Vector3, копируются при передаче. По умолчанию — пустой box.

Properties

СвойствоТипПо умолчаниюОписание
minVector3(+inf, +inf, +inf)
maxVector3(-inf, -inf, -inf)

Methods

.isBox3()

Возвращает true. Фасад проверки типа.

.set( min, max )

Устанавливает min и max, копируя из переданных векторов. Возвращает self.

Возвращает новый Box3 с теми же min и max.

Возвращает true, если max меньше min по любой оси.

Записывает размер box (max - min) в target и возвращает его. Возвращает (0,0,0), если пуст.

Записывает point, ограниченный так, чтобы лежать внутри этого box, в target и возвращает его.

.setFromVertices( vertices )

Строит box из массива "сырых" таблиц вершин вида {x, y, z, ...}, как используют генераторы геометрии и импортёры. Возвращает self.

.setFromObject( object )

Вычисляет мировые границы object и всего, что под ним. Каждый угол локального ограничивающего параллелепипеда каждого меша преобразуется по отдельности (а не путём прямого преобразования min/max box), так как преобразованные экстремумы повёрнутого box не совпадают с экстремумами его преобразованных углов. Возвращает self.

.equals( box )

Возвращает true, если этот box и box имеют равные min и max.
