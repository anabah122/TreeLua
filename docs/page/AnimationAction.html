AnimationAction

Controls the scheduling and playback of a single AnimationClip on an AnimationMixer. An action tracks its own local time, weight and loop mode, and is advanced each frame by the mixer that created it.

Constructor

AnimationAction.new(mixer, clip)

Actions are normally not constructed directly — use mixer:clipAction(clip), which returns a shared action per clip and caches it on the mixer.

Properties

PropertyTypeDefaultDescription
mixerAnimationMixer—Owning mixer.
clipAnimationClip—Clip this action plays.
timenumber0Current local playback time in seconds.
timeScalenumber1Playback speed multiplier.
weightnumber1Blend weight used when accumulating this action's pose against others running on the same mixer.
loopbooleantrueWhether the clip wraps around at its end instead of clamping.
pausedbooleanfalseWhen true, the action stops advancing but stays part of the mix.
enabledbooleantrueWhen false, the action is skipped entirely during mixing.

Methods

:play()

Enables the action and resets it to run from its current time, marking it active on the mixer.

:stop()

Disables the action and resets its time to 0.

:setEffectiveWeight(weight)

Sets weight, controlling how strongly this action's pose contributes when the mixer accumulates all enabled actions.

:setLoop(loop)

Sets whether the action's time wraps (true) or clamps to the clip duration (false).

:update(delta)

Advances time by delta * timeScale (a no-op while paused), wrapping or clamping against clip.duration depending on loop. Called internally by the mixer.

:evaluate(track, time)

Samples a single track of this action's clip at a given time and returns the interpolated value (a vector for translation/scale tracks, a quaternion for rotation tracks). This is the per-track entry point the mixer's PoseAccumulator calls for every active action so it can blend translation and scale linearly and rotation via quaternion slerp across all contributing actions — replacing the older per-clip sample() path that picked one whole clip instead of blending per track.

Differences from three.js

  • No fade (fadeIn/fadeOut/crossFadeTo), warp, or additive-blending API — weight must be set manually via setEffectiveWeight.
  • No clampWhenFinished, zeroSlopeAtStart/End, or repetition-count controls; looping is a plain boolean.

TreeLua / Animation

AnimationAction

Управляет планированием и воспроизведением одного AnimationClip на AnimationMixer. Экшен хранит собственное локальное время, вес и режим зацикливания и продвигается каждый кадр миксером, который его создал.

Constructor

AnimationAction.new(mixer, clip)

Экшены обычно не создаются напрямую — используйте mixer:clipAction(clip), который возвращает общий экшен для каждого клипа и кэширует его на миксере.

Properties

СвойствоТипПо умолчаниюОписание
mixerAnimationMixer—Владеющий миксер.
clipAnimationClip—Клип, который воспроизводит этот экшен.
timenumber0Текущее локальное время воспроизведения в секундах.
timeScalenumber1Множитель скорости воспроизведения.
weightnumber1Вес смешивания, используемый при накоплении позы этого экшена вместе с другими, работающими на том же миксере.
loopbooleantrueЗацикливается ли клип по достижении конца вместо ограничения (clamp).
pausedbooleanfalseЕсли true, экшен перестаёт продвигаться, но остаётся частью смешивания.
enabledbooleantrueЕсли false, экшен полностью пропускается при смешивании.

Methods

:play()

Включает экшен и сбрасывает его для запуска с текущего времени, помечая его активным на миксере.

:stop()

Отключает экшен и сбрасывает его время в 0.

:setEffectiveWeight(weight)

Устанавливает weight, определяя, насколько сильно поза этого экшена влияет при накоплении миксером всех включённых экшенов.

:setLoop(loop)

Устанавливает, зацикливается ли время экшена (true) или ограничивается длительностью клипа (false).

:update(delta)

Продвигает time на delta * timeScale (не действует, пока paused), зацикливая или ограничивая относительно clip.duration в зависимости от loop. Вызывается внутренне миксером.

:evaluate(track, time)

Сэмплирует одну дорожку клипа этого экшена в заданный момент времени и возвращает интерполированное значение (вектор для дорожек translation/scale, кватернион для дорожек rotation). Это точка входа по дорожкам, которую PoseAccumulator миксера вызывает для каждого активного экшена, чтобы смешивать translation и scale линейно, а rotation — через кватернионный slerp по всем участвующим экшенам — заменяя старый путь sample() по целому клипу, который выбирал один целый клип вместо смешивания по дорожкам.

Differences from three.js

  • Нет API для fade (fadeIn/fadeOut/crossFadeTo), warp или аддитивного смешивания — вес нужно устанавливать вручную через setEffectiveWeight.
  • Нет clampWhenFinished, zeroSlopeAtStart/End или управления количеством повторов; зацикливание — обычное булево значение.
