Matrix4

A 4x4 transformation matrix. Internally stored row-major (translation at indices 4, 8, 12), with a three.js-compatible column-major surface layered on top for anything reading against the three.js docs.

Constructor

Matrix4()

Creates a new identity matrix.

Matrix4.newFromArr( arr )

Creates a matrix from a flat 16-element row-major array.

Properties

The matrix itself is the array — its 16 elements live at indices 1..16 (row-major: row 1 is elements 1-4, row 2 is 5-8, and so on).

Methods

.set( n11, n12, ..., n44 )

Sets all 16 elements, given in visual row order — matching the three.js Matrix4.set argument order — even though storage is row-major internally.

.identity()

Resets this matrix to the identity matrix. Returns self.

.clone()

Returns a new Matrix4 with the same elements.

.copy( m )

Copies the elements of m into this matrix. Returns self.

.elements() / .asLinearArray()

Returns the 16 elements as a flat array in three.js's column-major order. asLinearArray is the name Vector3/Vector4's matrix-consuming methods look for.

.multiplyMatrices( a, b )

Sets this matrix to a * b. Equivalent to the original mul(A, B).

.multiply( m )

Sets this matrix to this * m, mutating in place. Returns self.

.premultiply( m )

Sets this matrix to m * this, mutating in place. Returns self.

.multiplyScalar( s )

Multiplies every element by s. Returns self.

.transpose()

Returns a new matrix that is the transpose of this one. Does not modify self.

.transposeSelf()

Transposes this matrix in place. Returns self.

.determinant()

Returns the determinant of this matrix.

.inverse()

Returns a new matrix that is the inverse of this one, or nil if the matrix is singular.

.invert()

Inverts this matrix in place. Returns self. If singular, resets to identity instead of returning nil.

.makePerspective( fov, aspect, near, far )

Sets this matrix to a perspective projection matrix. Facade over setProjectionMatrix.

.makeOrthographic( left, right, top, bottom, near, far )

Sets this matrix to an orthographic projection matrix, given frustum edges directly.

.lookAt( eye, target, up )

Sets this matrix's rotation basis to face from eye toward target (translation untouched), the same convention as three.js's Matrix4.lookAt.

.makeTranslation( x, y, z )

.makeScale( x, y, z )

.makeRotationX( theta ) / .makeRotationY( theta ) / .makeRotationZ( theta )

.makeRotationFromQuaternion( q )

.compose( position, quaternion, scale )

Builds this matrix from a position, quaternion, and scale. Accepts either {x,y,z}-style tables or plain arrays.

.decompose( position, quaternion, scale )

Extracts position, quaternion, and scale from this matrix, writing into the three arguments. Returns self.

.setPosition( x, y, z )

Sets the translation component. Also accepts a single vector-like table.

.toArray()

Alias for .elements().

.fromArray( array, offset )

Sets this matrix's elements from a flat column-major array, mirroring .elements().

.setOrthographicMatrix( fov, size, near, far, aspectRatio )

Original (pre-three.js-facade) orthographic projection setter, deriving frustum edges from a fov and size rather than taking them directly.

.setTransformationMatrix( translation, rotation, scale )

Original TRS composer taking plain Euler-angle arrays rather than a quaternion.

.setProjectionMatrix( fov, near, far, aspectRatio )

Original perspective projection setter.

.setViewMatrix( eye, target, up )

Builds a camera view matrix (the inverse of a camera's world transform) looking from eye toward target.

.mul( A, B )

Sets this matrix to the product A * B.

.mulVec4( x, y, z, w )

Multiplies this matrix by a column vector, returning the transformed x, y, z, w.

.mulPoint( point )

Transforms a point (w = 1) by this matrix, applying perspective divide. Returns a plain {x, y, z} table.

.mulVec3( vec )

Transforms a direction (w = 0, no translation) by this matrix. Returns a plain {x, y, z} table.

Differences from three.js

  • Storage is row-major, not column-major: translation lives at raw indices 4, 8, 12 instead of three.js's 13, 14, 15. Code that needs the three.js layout should read through .elements() / .asLinearArray() (which transpose on the way out) rather than indexing the matrix directly, and write through .set() or .fromArray(), which take the arguments/data in the same order the three.js docs describe.
  • Two parallel sets of transform builders exist: the original setProjectionMatrix/setOrthographicMatrix/setTransformationMatrix/setViewMatrix/mul (predate the three.js facade, some take fov+size or Euler arrays instead of a quaternion) alongside the three.js-named makePerspective/makeOrthographic/compose/multiplyMatrices. Both are kept because the internals and importers still call the originals directly.
  • .transpose() returns a new matrix; .transposeSelf() mutates in place and matches three.js's mutating transpose().
  • .inverse() returns a new matrix or nil on a singular matrix; .invert() mutates in place and resets to identity instead of returning nil, matching three.js's invert() behavior.
  • Matrix4.lookAt only builds the rotation basis (translation untouched), which is the inverse of setViewMatrix's already-inverted camera transform — the two are not interchangeable.

Matrix4

Матрица трансформации 4x4. Внутренне хранится в row-major порядке (трансляция по индексам 4, 8, 12), поверх которой надстроен совместимый с three.js column-major интерфейс для всего, что сверяется с документацией three.js.

Constructor

Matrix4()

Создаёт новую единичную матрицу.

Matrix4.newFromArr( arr )

Создаёт матрицу из плоского row-major массива из 16 элементов.

Properties

Матрица сама является массивом — её 16 элементов лежат по индексам 1..16 (row-major: строка 1 — элементы 1-4, строка 2 — 5-8, и так далее).

Methods

.set( n11, n12, ..., n44 )

Устанавливает все 16 элементов, заданных в визуальном порядке строк — соответствуя порядку аргументов Matrix4.set в three.js — хотя внутреннее хранение row-major.

.identity()

Сбрасывает эту матрицу к единичной. Возвращает self.

.clone()

Возвращает новую Matrix4 с теми же элементами.

.copy( m )

Копирует элементы m в эту матрицу. Возвращает self.

.elements() / .asLinearArray()

Возвращает 16 элементов как плоский массив в column-major порядке three.js. asLinearArray — имя, которое ищут матрично-потребляющие методы Vector3/Vector4.

.multiplyMatrices( a, b )

Устанавливает эту матрицу в a * b. Эквивалентно исходному mul(A, B).

.multiply( m )

Устанавливает эту матрицу в this * m, изменяя на месте. Возвращает self.

.premultiply( m )

Устанавливает эту матрицу в m * this, изменяя на месте. Возвращает self.

.multiplyScalar( s )

Умножает каждый элемент на s. Возвращает self.

.transpose()

Возвращает новую матрицу, являющуюся транспонированием этой. Не изменяет self.

.transposeSelf()

Транспонирует эту матрицу на месте. Возвращает self.

.determinant()

Возвращает определитель этой матрицы.

.inverse()

Возвращает новую матрицу, являющуюся обратной к этой, или nil, если матрица вырождена.

.invert()

Обращает эту матрицу на месте. Возвращает self. Если матрица вырождена, вместо nil сбрасывает её к единичной.

.makePerspective( fov, aspect, near, far )

Устанавливает эту матрицу как матрицу перспективной проекции. Фасад над setProjectionMatrix.

.makeOrthographic( left, right, top, bottom, near, far )

Устанавливает эту матрицу как матрицу ортографической проекции, задавая границы усечённой пирамиды напрямую.

.lookAt( eye, target, up )

Устанавливает базис вращения этой матрицы, чтобы смотреть от eye к target (трансляция не затрагивается) — та же конвенция, что и Matrix4.lookAt в three.js.

.makeTranslation( x, y, z )

.makeScale( x, y, z )

.makeRotationX( theta ) / .makeRotationY( theta ) / .makeRotationZ( theta )

.makeRotationFromQuaternion( q )

.compose( position, quaternion, scale )

Собирает эту матрицу из позиции, кватерниона и масштаба. Принимает таблицы вида {x,y,z} либо обычные массивы.

.decompose( position, quaternion, scale )

Извлекает позицию, кватернион и масштаб из этой матрицы, записывая их в три аргумента. Возвращает self.

.setPosition( x, y, z )

Устанавливает компонент трансляции. Также принимает одну таблицу вида вектора.

.toArray()

Псевдоним для .elements().

.fromArray( array, offset )

Устанавливает элементы этой матрицы из плоского column-major массива, зеркально к .elements().

.setOrthographicMatrix( fov, size, near, far, aspectRatio )

Исходный (до появления three.js-фасада) сеттер ортографической проекции, вычисляющий границы усечённой пирамиды из fov и size, а не принимающий их напрямую.

.setTransformationMatrix( translation, rotation, scale )

Исходный TRS-компоновщик, принимающий обычные массивы углов Эйлера вместо кватерниона.

.setProjectionMatrix( fov, near, far, aspectRatio )

Исходный сеттер перспективной проекции.

.setViewMatrix( eye, target, up )

Строит матрицу вида камеры (обратную мировому трансформу камеры), смотрящую от eye к target.

.mul( A, B )

Устанавливает эту матрицу в произведение A * B.

.mulVec4( x, y, z, w )

Умножает эту матрицу на вектор-столбец, возвращая преобразованные x, y, z, w.

.mulPoint( point )

Преобразует точку (w = 1) этой матрицей, применяя перспективное деление. Возвращает обычную таблицу {x, y, z}.

.mulVec3( vec )

Преобразует направление (w = 0, без трансляции) этой матрицей. Возвращает обычную таблицу {x, y, z}.

Differences from three.js

  • Хранение row-major, а не column-major: трансляция лежит по «сырым» индексам 4, 8, 12, а не 13, 14, 15, как в three.js. Коду, которому нужна раскладка three.js, следует читать через .elements() / .asLinearArray() (которые транспонируют на выходе), а не индексировать матрицу напрямую, и записывать через .set() или .fromArray(), которые принимают аргументы/данные в том же порядке, что описан в документации three.js.
  • Существуют два параллельных набора построителей трансформаций: исходные setProjectionMatrix/setOrthographicMatrix/setTransformationMatrix/setViewMatrix/mul (появились раньше three.js-фасада, некоторые принимают fov+size или массивы углов Эйлера вместо кватерниона) наряду с названными по three.js makePerspective/makeOrthographic/compose/multiplyMatrices. Оба набора сохранены, потому что внутренние механизмы и импортёры до сих пор напрямую вызывают исходные.
  • .transpose() возвращает новую матрицу; .transposeSelf() изменяет на месте и соответствует мутирующему transpose() в three.js.
  • .inverse() возвращает новую матрицу или nil при вырожденной матрице; .invert() изменяет на месте и вместо nil сбрасывает к единичной, соответствуя поведению invert() в three.js.
  • Matrix4.lookAt строит только базис вращения (трансляция не затрагивается), что является обратным к уже инвертированному трансформу камеры в setViewMatrix — эти два метода не взаимозаменяемы.
