TreeLua / Materials

MeshStandardMaterial

Extends Material, inherits its API. Named for the three.js class the glTF importer's output maps onto: glTF materials are metallic-roughness, and so is this field set. The bundled shader is Cook-Torrance, so every field here reaches it. Adds the three texture slots (roughnessMap, metalnessMap, emissiveMap) that only make sense alongside PBR factors.

Methods

.copy(source)

Calls Material.copy, then copies the three map fields.

.fromImporter(mat)

Builds a MeshStandardMaterial from an importer material record (the shared shape both the engine's importers emit: { name, baseColor, texture, metallic, roughness, emissive, emissiveTexture, normalTexture, occlusionTexture, alphaMode, doubleSided, ... }). glTF packs metalness and roughness into one texture, channels B and G, so metalnessMap and roughnessMap both point at it. alphaMode == "BLEND" sets transparent = true; "MASK" sets alphaTest from alphaCutoff (default 0.5). doubleSided sets side = "double". Has no three.js equivalent — it is TreeLua's importer glue.

Differences from three.js

  • .fromImporter(mat) is a TreeLua-only factory with no three.js counterpart.
  • In .fromImporter, the metallic/roughness factors from the source material are only applied when a metallic-roughness map is present (metalness = mrMap and mat.metallic or 0, roughness = mrMap and mat.roughness or 1). Without a map the surface is forced to a plain matte dielectric regardless of what factor values the exporter left behind — a deliberate workaround for exporters (Mixamo is called out in the source) that write non-trivial metallic/roughness factors onto every material even when no map backs them, which would otherwise render skin as half metal.

MeshStandardMaterial

Наследует Material, наследует её API. Названа в честь класса three.js, на который отображается вывод glTF-импортёра: материалы glTF — metallic-roughness, и этот набор полей тоже. Встроенный шейдер — Cook-Torrance, поэтому каждое поле здесь доходит до него. Добавляет три текстурных слота (roughnessMap, metalnessMap, emissiveMap), которые имеют смысл только вместе с PBR-факторами.

Methods

.copy(source)

Вызывает Material.copy, затем копирует три поля карт.

.fromImporter(mat)

Строит MeshStandardMaterial из записи материала импортёра (общая форма, которую выдают оба импортёра движка: { name, baseColor, texture, metallic, roughness, emissive, emissiveTexture, normalTexture, occlusionTexture, alphaMode, doubleSided, ... }). glTF упаковывает metalness и roughness в одну текстуру, каналы B и G, поэтому metalnessMap и roughnessMap обе указывают на неё. alphaMode == "BLEND" устанавливает transparent = true; "MASK" устанавливает alphaTest из alphaCutoff (по умолчанию 0.5). doubleSided устанавливает side = "double". Не имеет аналога в three.js — это связующий код импортёра TreeLua.

Differences from three.js

  • .fromImporter(mat) — фабрика, существующая только в TreeLua, без аналога в three.js.
  • В .fromImporter факторы metallic/roughness из исходного материала применяются только при наличии карты metallic-roughness (metalness = mrMap and mat.metallic or 0, roughness = mrMap and mat.roughness or 1). Без карты поверхность принудительно становится обычным матовым диэлектриком независимо от того, какие значения факторов оставил экспортёр — намеренный обход для экспортёров (в исходнике упомянут Mixamo), которые записывают нетривиальные факторы metallic/roughness в каждый материал даже без карты за ними, что иначе рендерило бы кожу наполовину металлической.
