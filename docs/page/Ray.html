Ray

A ray defined by an origin and a direction. The direction is assumed to be normalized — the intersection methods return a distance measured along it, so a non-unit direction silently rescales every result.

Constructor

Ray( origin, direction )

origin, direction — Vector3s, cloned in. Default to (0,0,0) and (0,0,-1).

Properties

PropertyTypeDefaultDescription
originVector3(0,0,0)
directionVector3(0,0,-1)Assumed unit length.

Methods

.isRay()

Returns true. Type-check facade.

.set( origin, direction )

Sets origin and direction by copying. Returns self.

.clone()

Returns a new Ray with the same origin and direction.

.copy( ray )

Copies ray's origin and direction into this ray. Returns self.

.at( t, target )

Writes the point at distance t along this ray into target and returns it.

.lookAt( v )

Points this ray's direction at v, normalized. Returns self.

.recast( t )

Moves the ray's origin to the point at distance t along it, keeping the same direction. Returns self.

.closestPointToPoint( point, target )

Writes the nearest point on this ray to point into target and returns it. Clamped at the origin — a point behind the ray is not on it.

.distanceToPoint( point )

Returns the distance from point to this ray.

.distanceSqToPoint( point )

Returns the squared distance from point to this ray.

.applyMatrix4( m )

Transforms this ray by matrix m, in place. Transforms the tip (origin + direction) as a point before moving the origin, then rebuilds and renormalizes the direction, so translation cancels out and any scale is normalized away. Returns self.

.intersectSphere( sphere, target )

Writes the nearest intersection point with sphere into target and returns it, or nil if there is none.

.intersectsSphere( sphere )

Returns true if this ray intersects sphere.

.distanceToPlane( plane )

Returns the distance along this ray to plane, or nil if parallel and not coincident, or if the intersection is behind the origin.

.intersectPlane( plane, target )

Writes the intersection point with plane into target and returns it, or nil if none.

.intersectsPlane( plane )

Returns true if this ray intersects plane.

.intersectBox( box, target )

Writes the nearest intersection point with box into target and returns it, or nil if none. Implemented as a slab test against each pair of parallel box faces.

.intersectsBox( box )

Returns true if this ray intersects box.

.intersectTriangle( a, b, c, backfaceCulling, target )

Writes the intersection point with triangle (a, b, c) into target and returns it, or nil if none. Uses the Moeller-Trumbore algorithm. When backfaceCulling is true, triangles whose winding faces away from the ray are skipped.

.equals( ray )

Returns true if this ray and ray have equal origin and direction.

TreeLua / Math

Ray

Луч, заданный точкой начала и направлением. Направление считается нормализованным — методы пересечения возвращают расстояние, измеренное вдоль него, поэтому неединичное направление незаметно масштабирует все результаты.

Constructor

Ray( origin, direction )

origin, direction — Vector3, клонируются при передаче. По умолчанию (0,0,0) и (0,0,-1).

Properties

СвойствоТипПо умолчаниюОписание
originVector3(0,0,0)
directionVector3(0,0,-1)Предполагается единичной длины.

Methods

.isRay()

Возвращает true. Фасад проверки типа.

.set( origin, direction )

Устанавливает origin и direction копированием. Возвращает self.

.clone()

Возвращает новый Ray с той же точкой начала и направлением.

.copy( ray )

Копирует origin и direction из ray в этот луч. Возвращает self.

.at( t, target )

Записывает точку на расстоянии t вдоль этого луча в target и возвращает его.

.lookAt( v )

Направляет направление этого луча на v, нормализуя. Возвращает self.

.recast( t )

Переносит начало луча в точку на расстоянии t вдоль него, сохраняя то же направление. Возвращает self.

.closestPointToPoint( point, target )

Записывает ближайшую к point точку на этом луче в target и возвращает его. Ограничена началом луча — точка позади луча ему не принадлежит.

.distanceToPoint( point )

Возвращает расстояние от point до этого луча.

.distanceSqToPoint( point )

Возвращает квадрат расстояния от point до этого луча.

.applyMatrix4( m )

Трансформирует этот луч матрицей m на месте. Трансформирует конец луча (origin + direction) как точку до переноса начала, затем пересчитывает и заново нормализует направление, так что перенос сокращается, а любой масштаб нормализуется. Возвращает self.

.intersectSphere( sphere, target )

Записывает ближайшую точку пересечения со sphere в target и возвращает его, либо nil, если пересечения нет.

.intersectsSphere( sphere )

Возвращает true, если этот луч пересекает sphere.

.distanceToPlane( plane )

Возвращает расстояние вдоль этого луча до plane, либо nil, если луч параллелен и не совпадает с плоскостью, либо если пересечение находится позади начала луча.

.intersectPlane( plane, target )

Записывает точку пересечения с plane в target и возвращает его, либо nil, если пересечения нет.

.intersectsPlane( plane )

Возвращает true, если этот луч пересекает plane.

.intersectBox( box, target )

Записывает ближайшую точку пересечения с box в target и возвращает его, либо nil, если пересечения нет. Реализовано как slab-тест по каждой паре параллельных граней параллелепипеда.

.intersectsBox( box )

Возвращает true, если этот луч пересекает box.

.intersectTriangle( a, b, c, backfaceCulling, target )

Записывает точку пересечения с треугольником (a, b, c) в target и возвращает его, либо nil, если пересечения нет. Использует алгоритм Мёллера-Трумбора. Если backfaceCulling равен true, треугольники, обход которых направлен от луча, пропускаются.

.equals( ray )

Возвращает true, если у этого луча и ray равны origin и direction.
