TreeLua / Controls

FlyControls

TreeLua-native free-flight camera controller: no three.js class shares this exact name and API, but the behavior mirrors three.js's addon FlyControls/FirstPersonControls — WASD-style translation plus mouse-look rotation, unconstrained by any up-vector or target orbit point.

Constructor

FlyControls.new(camera, params)

Wraps a PerspectiveCamera with WASD + mouse-look input handling. The camera stays a normal Object3D — it can still be parented, animated or replaced — since FlyControls only drives its position/rotation each frame rather than owning a view matrix. params is an optional table overriding any of the properties below (e.g. movementSpeed, lookSpeed, keys, lockMouse). By default the constructor calls love.mouse.setRelativeMode(true) to lock the cursor.

Properties

PropertyTypeDefaultDescription
objectCamera—The camera being controlled.
enabledbooleantrueWhen false, input is ignored by update/mousemoved/wheelmoved.
yawnumberπHorizontal look angle in radians, kept independently of the camera's quaternion to avoid drift.
pitchnumber0Vertical look angle in radians, clamped just short of ±π/2.
movementSpeednumber5Units per second of translation while a movement key is held.
speedMin / speedMaxnumber0.1 / 500Clamp range for movementSpeed as adjusted by the scroll wheel.
lookSpeednumber0.002Radians per pixel of mouse movement applied to yaw/pitch.
slowModifiernumber0.2Multiplier applied to movementSpeed while a slow-move key is held.
keystableWASD + Q/E + shiftKey bindings: forward, back, left, right, up, down, slow (the last may be a single key or an array of keys).
lockMousebooleantrueWhether the constructor/dispose toggle love.mouse.setRelativeMode.

Methods

:update(dt)

Reads held movement keys and translates the camera along its forward/right/up axes (forward is flattened so vertical look doesn't affect walking speed), scaled by movementSpeed * dt and slowModifier if the slow key is held.

:mousemoved(dx, dy)

Adjusts yaw/pitch by the mouse delta scaled by lookSpeed, clamps pitch away from the poles, and re-applies the resulting look direction to the camera via lookAt.

:wheelmoved(dy)

Multiplies movementSpeed by 1.2 or 1/1.2 depending on scroll direction, clamped to [speedMin, speedMax].

:forward()

Returns the current forward direction as a Vector3, derived from yaw/pitch.

:right()

Returns the current right direction (forward crossed with world up).

:forwardFlat()

Returns the forward direction with pitch zeroed out, used for movement so looking up/down doesn't change walking speed.

:dispose()

Disables the controls and releases the mouse lock if lockMouse was set.

Differences from three.js

  • No matching class in three.js core; closest analogues are the addon controls FlyControls and FirstPersonControls, neither of which TreeLua mirrors property-for-property — this is a from-scratch, LÖVE-native implementation.
  • Reads love.keyboard/love.mouse directly and expects the host application to forward love.update, love.mousemoved and love.wheelmoved — there is no DOM element to attach listeners to.

TreeLua / Controls

FlyControls

Собственный для TreeLua контроллер камеры свободного полёта: в three.js нет класса с точно таким же именем и API, но поведение повторяет аддон-контроллеры three.js FlyControls/FirstPersonControls — перемещение в стиле WASD плюс вращение мышью, без ограничений вектором up или точкой орбиты.

Constructor

FlyControls.new(camera, params)

Оборачивает PerspectiveCamera обработкой ввода WASD + mouse-look. Камера остаётся обычным Object3D — её всё ещё можно перепривязать, анимировать или заменить — так как FlyControls лишь управляет её position/rotation каждый кадр, а не владеет собственной view-матрицей. params — необязательная таблица, переопределяющая любое из свойств ниже (например, movementSpeed, lookSpeed, keys, lockMouse). По умолчанию конструктор вызывает love.mouse.setRelativeMode(true), чтобы заблокировать курсор.

Methods

:update(dt)

Считывает удерживаемые клавиши движения и перемещает камеру вдоль её осей forward/right/up (forward сглаживается по вертикали, чтобы взгляд вверх/вниз не влиял на скорость ходьбы), масштабируя на movementSpeed * dt и slowModifier, если удержана клавиша замедления.

:mousemoved(dx, dy)

Изменяет yaw/pitch на дельту мыши, масштабированную lookSpeed, ограничивает pitch от полюсов и заново применяет полученное направление взгляда к камере через lookAt.

:wheelmoved(dy)

Умножает movementSpeed на 1.2 или 1/1.2 в зависимости от направления прокрутки, ограничивая значением в диапазоне [speedMin, speedMax].

:forward()

Возвращает текущее направление вперёд как Vector3, вычисленное из yaw/pitch.

:right()

Возвращает текущее направление вправо (forward, скрещенный с мировым up).

:forwardFlat()

Возвращает направление вперёд с обнулённым pitch, используется для перемещения, чтобы взгляд вверх/вниз не менял скорость ходьбы.

:dispose()

Отключает контроллер и снимает блокировку мыши, если был установлен lockMouse.

Differences from three.js

  • Нет соответствующего класса в ядре three.js; ближайшие аналоги — аддон-контроллеры FlyControls и FirstPersonControls, ни один из которых TreeLua не повторяет свойство в свойство — это реализация, написанная с нуля специально для LÖVE.
  • Читает love.keyboard/love.mouse напрямую и ожидает, что хост-приложение будет пересылать love.update, love.mousemoved и love.wheelmoved — DOM-элемента для подключения слушателей нет.
