Scene

The root of a scene graph. Extends Object3D and inherits its full API, adding the frame-wide settings the renderer reads once per draw: the clear colour and an optional material override.

local scene = Scene:new()
scene.background = Color:new(0x101018)
scene:add(mesh)
renderer:render(scene, camera)

Constructor

Scene()

Creates a new Scene with background = nil and overrideMaterial = nil.

Properties

PropertyTypeDefaultDescription
backgroundColornilnil means "do not clear", matching three.js where a null background leaves whatever was in the buffer.
overrideMaterialMaterialnilWhen set, every mesh draws with this material instead of its own.

Otherwise inherits all of Object3D's properties.

Methods

.isScene()

Returns true.

.setBackground(value)

Convenience the renderer also accepts directly: pass nil to clear, an existing Color to use as-is, or a hex/name value to wrap in a new Color.

.copy(source, recursive)

Extends Object3D.copy: clones .background and carries over .overrideMaterial by reference.

All other methods come from Object3D.

Scene

Корень графа сцены. Наследует Object3D и получает весь его API, добавляя общекадровые настройки, которые рендерер читает один раз на отрисовку: цвет очистки и опциональную подмену материала.

local scene = Scene:new()
scene.background = Color:new(0x101018)
scene:add(mesh)
renderer:render(scene, camera)

Constructor

Scene()

Создаёт новую Scene с background = nil и overrideMaterial = nil.

Properties

СвойствоТипПо умолчаниюОписание
backgroundColornilnil означает "не очищать", как и в three.js, где null-фон оставляет в буфере то, что там было.
overrideMaterialMaterialnilЕсли задан, каждый меш рисуется этим материалом вместо своего.

В остальном наследует все свойства Object3D.

Methods

.isScene()

Возвращает true.

.setBackground(value)

Удобный метод, который рендерер тоже принимает напрямую: передайте nil для очистки, существующий Color, чтобы использовать как есть, или hex/именованное значение, чтобы обернуть в новый Color.

.copy(source, recursive)

Расширяет Object3D.copy: клонирует .background и переносит .overrideMaterial по ссылке.

Все остальные методы приходят из Object3D.
