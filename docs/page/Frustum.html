Frustum

The six planes bounding a camera's view volume. Planes face inward, so a point inside the frustum has a positive distance to all six, and a single negative distance is enough to reject it.

Constructor

Frustum( p0, p1, p2, p3, p4, p5 )

Six optional Planes (left, right, bottom, top, near, far); any omitted are created as default Planes.

Properties

PropertyTypeDefaultDescription
planestable of 6 Planes—Order: left, right, bottom, top, near, far.

Methods

.isFrustum()

Returns true. Type-check facade.

.set( p0, p1, p2, p3, p4, p5 )

Sets all six planes by copying. Returns self.

.clone()

Returns a new Frustum with copies of the same six planes.

.copy( frustum )

Copies frustum's planes into this frustum. Returns self.

.setFromProjectionMatrix( m )

Extracts the six frustum planes from a view-projection matrix m using the Gribb-Hartmann method, then normalizes each so plane distances are true (not merely proportional) signed distances. Returns self.

.containsPoint( point )

Returns true if point lies inside the frustum.

.intersectsSphere( sphere )

Returns true if sphere overlaps the frustum.

.intersectsBox( box )

Returns true if box overlaps the frustum. Tests only the box corner furthest along each plane's normal — if even that corner is outside, the whole box is.

.intersectsObject( object )

Returns true if object's bounding sphere, pushed into world space, overlaps the frustum. Returns false if object has no geometry. Errs toward accepting when the geometry has no bounding sphere available, since a false positive only costs a draw call while a false negative pops geometry out of view.

Differences from three.js

  • .setFromProjectionMatrix reads matrix rows assuming TreeLua's row-major Matrix4 storage (rows at indices 1-4, 5-8, 9-12, 13-16), so the element access differs from three.js's column-major version even though the Gribb-Hartmann derivation is the same.

TreeLua / Math

Frustum

Шесть плоскостей, ограничивающих объём видимости камеры. Плоскости направлены внутрь, поэтому точка внутри фрустума имеет положительное расстояние до всех шести, а одного отрицательного расстояния достаточно, чтобы отбросить точку.

Constructor

Frustum( p0, p1, p2, p3, p4, p5 )

Шесть необязательных Plane (left, right, bottom, top, near, far); любые пропущенные создаются как Plane по умолчанию.

Properties

СвойствоТипПо умолчаниюОписание
planesтаблица из 6 Plane—Порядок: left, right, bottom, top, near, far.

Methods

.isFrustum()

Возвращает true. Фасад проверки типа.

.set( p0, p1, p2, p3, p4, p5 )

Устанавливает все шесть плоскостей копированием. Возвращает self.

.clone()

Возвращает новый Frustum с копиями тех же шести плоскостей.

.copy( frustum )

Копирует плоскости из frustum в этот фрустум. Возвращает self.

.setFromProjectionMatrix( m )

Извлекает шесть плоскостей фрустума из матрицы вида-проекции m методом Гриба-Хартманна, затем нормализует каждую, чтобы расстояния до плоскостей были истинными знаковыми расстояниями (а не просто пропорциональными). Возвращает self.

.containsPoint( point )

Возвращает true, если point лежит внутри фрустума.

.intersectsSphere( sphere )

Возвращает true, если sphere пересекается с фрустумом.

.intersectsBox( box )

Возвращает true, если box пересекается с фрустумом. Проверяется только угол параллелепипеда, наиболее удалённый вдоль нормали каждой плоскости — если даже этот угол снаружи, снаружи весь параллелепипед.

.intersectsObject( object )

Возвращает true, если ограничивающая сфера object, перенесённая в мировое пространство, пересекается с фрустумом. Возвращает false, если у object нет геометрии. Склоняется в сторону принятия, когда у геометрии нет доступной ограничивающей сферы, поскольку ложное срабатывание стоит лишь один вызов отрисовки, а ложный отказ выталкивает геометрию из поля зрения.

Differences from three.js

  • .setFromProjectionMatrix читает строки матрицы, исходя из хранения Matrix4 в TreeLua по строкам (строки по индексам 1-4, 5-8, 9-12, 13-16), поэтому доступ к элементам отличается от версии three.js со столбцовым хранением, хотя вывод по методу Гриба-Хартманна тот же.
