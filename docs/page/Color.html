Color

An RGB color, three components only — no alpha. Transparency lives on the material as opacity, matching three.js. Values are unclamped floats in the 0..1 range, the same range LÖVE 11's love.graphics.setColor uses, so colors pass through untouched and values above 1 stay usable for emissive tinting.

Constructor

Color( r, g, b )

Flexible constructor, matching .set():

  • Color() — white
  • Color(0xff8800) — hex integer
  • Color("red") / Color("#ff8800") / Color("#f80") — string
  • Color(1, 0.5, 0) — r, g, b components

Color.NAMES is a static table of recognized CSS-style color names (a trimmed subset — black, white, red, green, blue, yellow, cyan, magenta, gray/grey, orange, purple), used by .setStyle().

Methods

.set( r, g, b )

Sets the color from a string (name or hex), a color-like table, a single hex number, or three components — dispatches to setStyle, setRGB, or setHex based on argument types. Returns self.

.setRGB( r, g, b )

Sets the components directly. Returns self.

.setScalar( s )

Sets r, g, b all to s. Returns self.

.setHex( hex )

Sets the color from a 24-bit hex integer. Returns self.

.setStyle( style )

Sets the color from a CSS-like string: a name from Color.NAMES, "#rrggbb", or the shorthand "#rgb". Unrecognized input leaves the color unchanged rather than resetting to black. Returns self.

.setHSL( h, s, l )

Sets the color from hue/saturation/lightness, each in 0..1. Returns self.

.getHex()

Returns the color as a 24-bit hex integer, with components clamped to 0..1 before conversion.

.getHexString()

Returns the color as a 6-digit lowercase hex string, no leading #.

.getHSL()

Returns h, s, l as three separate values, each in 0..1.

.clone()

Returns a new Color with the same r, g, b.

.copy( c )

Copies c's components into this color. Returns self.

.add( c )

Adds c's components to this color, in place. Returns self.

.sub( c )

Subtracts c's components from this color, in place, clamped to a minimum of 0. Returns self.

.multiply( c )

Multiplies this color by c component-wise, in place. Returns self.

.multiplyScalar( s )

Multiplies each component by s, in place. Returns self.

.lerp( c, alpha )

Linearly interpolates this color toward c by alpha, in place. Returns self.

.equals( c )

Returns true if this color and c have identical r, g, b.

.toArray( alpha )

Returns {r, g, b, alpha or 1}.

.fromArray( array, offset )

Sets r, g, b from array starting at offset. Returns self.

Differences from three.js

  • No alpha channel on the class itself — three.js's Color is also RGB-only, so this matches; alpha only appears as an optional argument to .toArray() for convenience when feeding LÖVE's color arrays.
  • Color.NAMES is a small hand-picked subset of the ~150 CSS color keywords three.js recognizes, not the full X11/CSS list.

Color

RGB-цвет, только три компонента — без альфа-канала. Прозрачность живёт на материале как opacity, как и в three.js. Значения — неограниченные числа с плавающей точкой в диапазоне 0..1, том же, что использует love.graphics.setColor в LÖVE 11, поэтому цвета проходят без изменений, а значения выше 1 остаются полезны для эмиссивной подсветки.

Constructor

Color( r, g, b )

Гибкий конструктор, соответствующий .set():

  • Color() — белый
  • Color(0xff8800) — hex-целое
  • Color("red") / Color("#ff8800") / Color("#f80") — строка
  • Color(1, 0.5, 0) — компоненты r, g, b

Properties

rnumber1
gnumber1
bnumber1

Color.NAMES — статическая таблица распознаваемых CSS-подобных названий цветов (урезанное подмножество — black, white, red, green, blue, yellow, cyan, magenta, gray/grey, orange, purple), используемая .setStyle().

Methods

.set( r, g, b )

Устанавливает цвет из строки (имя или hex), таблицы, похожей на цвет, одиночного hex-числа или трёх компонентов — в зависимости от типов аргументов делегирует в setStyle, setRGB или setHex. Возвращает self.

.setRGB( r, g, b )

Устанавливает компоненты напрямую. Возвращает self.

.setScalar( s )

Устанавливает r, g, b равными s. Возвращает self.

.setHex( hex )

Устанавливает цвет из 24-битного hex-целого. Возвращает self.

.setStyle( style )

Устанавливает цвет из CSS-подобной строки: имени из Color.NAMES, "#rrggbb" или сокращённого "#rgb". Нераспознанный ввод оставляет цвет без изменений, а не сбрасывает его в чёрный. Возвращает self.

.setHSL( h, s, l )

Устанавливает цвет из оттенка/насыщенности/светлоты, каждое значение в 0..1. Возвращает self.

.getHex()

Возвращает цвет как 24-битное hex-целое, компоненты ограничиваются до 0..1 перед преобразованием.

.getHexString()

Возвращает цвет как 6-значную строку hex в нижнем регистре, без ведущего #.

.getHSL()

Возвращает h, s, l как три отдельных значения, каждое в 0..1.

.clone()

Возвращает новый Color с теми же r, g, b.

.copy( c )

Копирует компоненты c в этот цвет. Возвращает self.

.add( c )

Прибавляет компоненты c к этому цвету на месте. Возвращает self.

.sub( c )

Вычитает компоненты c из этого цвета на месте, с ограничением снизу нулём. Возвращает self.

.multiply( c )

Покомпонентно умножает этот цвет на c на месте. Возвращает self.

.multiplyScalar( s )

Умножает каждый компонент на s на месте. Возвращает self.

.lerp( c, alpha )

Линейно интерполирует этот цвет к c на величину alpha, на месте. Возвращает self.

.equals( c )

Возвращает true, если этот цвет и c имеют одинаковые r, g, b.

.toArray( alpha )

Возвращает {r, g, b, alpha or 1}.

.fromArray( array, offset )

Устанавливает r, g, b из массива, начиная с offset. Возвращает self.

Differences from three.js

  • У класса нет альфа-канала — Color в three.js тоже только RGB, так что это совпадает; alpha появляется лишь как необязательный аргумент .toArray() для удобства при передаче в цветовые массивы LÖVE.
  • Color.NAMES — небольшое отобранное вручную подмножество из ~150 CSS-ключевых слов цвета, которые распознаёт three.js, а не полный список X11/CSS.
