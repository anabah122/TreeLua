Material

Base material: the uniform side of a shader program. The engine ships one forward-lit shader, so a material never selects a program — only feeds its uniforms. Every PBR field (metalness, roughness, emissive, normal/AO maps) is declared here with a default rather than pushed down to MeshStandardMaterial, so the renderer can send them unconditionally: an absent map means a plain matte dielectric, not a nil check at the send site.

Methods

.isMaterial()

Returns true.

.extend(typeName)

TreeLua's subclassing hook, used by MeshStandardMaterial. Returns a subclass whose :new() sets .type to typeName after delegating to the parent constructor.

.baseColorArray()

Returns { r, g, b, opacity }, the shape the shader's u_baseColor uniform wants: rgb from .color, alpha from .opacity, matching how three.js keeps the two separate.

.setValues(params)

Assigns each key in params onto the material. A color value that is not a table is passed through self.color:set(v) instead of overwriting the Color object.

.copy(source)

.clone()

.dispose()

Clears .map. LÖVE frees images by garbage collection, so this exists for API compatibility with three.js's explicit GPU-resource teardown, not because it releases anything itself.

Differences from three.js

  • PBR fields (metalness, roughness, emissive, normalMap, aoMap, …) live on the base Material rather than only on MeshStandardMaterial, since this engine has a single shader and every material feeds the same uniform set.
  • .extend(typeName) is TreeLua's subclassing hook and has no three.js equivalent.

TreeLua / Materials

Material

Базовый материал: единообразная сторона шейдерной программы. Движок поставляется с одним forward-lit шейдером, поэтому материал никогда не выбирает программу — только подаёт её uniforms. Каждое PBR-поле (metalness, roughness, emissive, карты normal/AO) объявлено здесь со значением по умолчанию, а не спущено вниз в MeshStandardMaterial, чтобы рендерер мог отправлять их безусловно: отсутствующая карта означает обычный матовый диэлектрик, а не проверку на nil в месте отправки.

Material(params)

Methods

.isMaterial()

Возвращает true.

.extend(typeName)

Хук наследования TreeLua, используется MeshStandardMaterial. Возвращает подкласс, чей :new() устанавливает .type в typeName после делегирования родительскому конструктору.

.baseColorArray()

Возвращает { r, g, b, opacity } — форму, которую хочет uniform шейдера u_baseColor: rgb из .color, альфа из .opacity, так же как three.js хранит их раздельно.

.setValues(params)

Присваивает каждый ключ из params материалу. Значение color, не являющееся таблицей, передаётся через self.color:set(v) вместо перезаписи объекта Color.

.copy(source)

.clone()

.dispose()

Очищает .map. LÖVE освобождает изображения через сборщик мусора, поэтому этот метод существует ради совместимости API с явным высвобождением GPU-ресурсов в three.js, а не потому что сам что-то освобождает.

Differences from three.js

  • PBR-поля (metalness, roughness, emissive, normalMap, aoMap, …) живут в базовом Material, а не только в MeshStandardMaterial, поскольку в этом движке один шейдер и каждый материал подаёт один и тот же набор uniforms.
  • .extend(typeName) — хук наследования TreeLua и не имеет аналога в three.js.
