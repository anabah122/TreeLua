PointLight

Extends Light, inherits its API. Omnidirectional light with distance-based falloff, radiating from its world position.

local lamp = PointLight:new(0xffeecc, 2, 10)
lamp.position:set(0, 3, 0)
scene:add(lamp)

Constructor

PointLight(color, intensity, distance, decay)

Same color/intensity defaults as Light. distance defaults to 0 (never cuts off). decay defaults to 2, the physical inverse-square falloff and three.js's default.

Properties

PropertyTypeDefaultDescription
distancenumber00 means the light never cuts off.
decaynumber2Physical inverse-square falloff.

Inherits color and intensity from Light.

Methods

.isPointLight()

Returns true.

.getPower()

.setPower(power)

three.js's luminous-power accessor pair: intensity expressed in candela, converted via power = intensity * 4π.

.worldPosition(target)

Updates the world matrix and returns the light's world-space position. No direct three.js equivalent — three.js's renderer reads matrixWorld position internally rather than exposing this as a public method.

.copy(source, recursive)

Differences from three.js

  • Not sampled by the bundled shader. The shader takes one directional light plus ambient only; a PointLight sits in the scene graph, tracks its transform, and offers .worldPosition(), but contributes no illumination yet. It exists so scene code written against three.js loads instead of erroring on a missing class.
  • .worldPosition(target) is a TreeLua-only facade with no three.js equivalent.

TreeLua / Lights

PointLight

Наследует Light, наследует её API. Всенаправленный источник света с затуханием по расстоянию, излучающий из своей мировой позиции.

local lamp = PointLight:new(0xffeecc, 2, 10)
lamp.position:set(0, 3, 0)
scene:add(lamp)

Constructor

PointLight(color, intensity, distance, decay)

Те же значения по умолчанию для color/intensity, что и у Light. distance по умолчанию 0 (никогда не обрезается). decay по умолчанию 2 — физическое затухание по обратному квадрату, соответствует умолчанию three.js.

Properties

СвойствоТипПо умолчаниюОписание
distancenumber00 означает, что свет никогда не обрезается.
decaynumber2Физическое затухание по обратному квадрату.

Наследует color и intensity от Light.

Methods

.isPointLight()

Возвращает true.

.getPower()

.setPower(power)

Пара акцессоров светового потока из three.js: intensity, выраженная в канделах, конвертируется через power = intensity * 4π.

.worldPosition(target)

Обновляет мировую матрицу и возвращает позицию источника света в мировом пространстве. Нет прямого аналога в three.js — рендерер three.js читает позицию из matrixWorld внутренне, а не предоставляет это как публичный метод.

.copy(source, recursive)

Differences from three.js

  • Не сэмплируется встроенным шейдером. Шейдер принимает только один направленный источник плюс ambient; PointLight находится в графе сцены, отслеживает свой трансформ и предоставляет .worldPosition(), но пока не вносит вклада в освещение. Он существует, чтобы код сцены, написанный под three.js, загружался, а не падал с ошибкой из-за отсутствующего класса.
  • .worldPosition(target) — фасад, существующий только в TreeLua, без аналога в three.js.
