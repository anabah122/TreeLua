Vector3

A 3-component vector, used to represent points, directions, and any other triple of numbers in 3D space.

Constructor

Vector3( x, y, z )

x, y, z — the component values. Default 0 for each.

Properties

PropertyTypeDefaultDescription
xnumber0The x component.
ynumber0The y component.
znumber0The z component.

Methods

.clone()

Returns a new Vector3 with the same x, y, z values.

.copy( v )

Copies the values of v into this vector and returns self.

.set( x, y, z )

Sets the x, y, z components and returns self.

.equals( v )

Returns true if this vector and v have identical x, y, z components.

.length()

Returns the Euclidean length of this vector.

.lengthSq()

Returns the squared length of this vector. Faster than .length() when only comparing magnitudes.

.distanceTo( v )

Returns the Euclidean distance between this vector and v.

.distanceToSquared( v )

Returns the squared distance between this vector and v.

.dot( v )

Returns the dot product of this vector and v.

.applyMatrix4( m )

Transforms this vector by the 4x4 matrix m (returns a new vector), treating it as a point (applies translation).

.applyQuaternion( q )

Rotates this vector by quaternion q, returning a new vector.

.transformDirection( m )

Transforms the direction of this vector by matrix m and normalizes the result, without applying translation. Returns a new vector.

Differences from three.js

  • Vector3 exposes two parallel method families instead of three.js's single mutating API. The immutable group (add, sub, mul, div, normalize, lerp, min, max, clamp, floor, ceil, round, and their scalar variants) always returns a new Vector3 and leaves self untouched. The mutating, three.js-compatible group — addV, subV, normalizeSelf, lerpSelf, minSelf, maxSelf, clampSelf, floorSelf, ceilSelf, roundSelf — mutates self in place and returns self, matching the behavior of three.js's add/sub/normalize/etc.
  • Both groups exist side by side so call sites can opt into whichever style fits: the immutable group avoids aliasing bugs common in hot loops, while the *Self group lets ported three.js code and performance-critical paths mutate without allocating.

.maxSelf( v )

.ceilSelf()

Vector3

Трёхкомпонентный вектор, используется для представления точек, направлений и любых других троек чисел в 3D-пространстве.

Constructor

Vector3( x, y, z )

x, y, z — значения компонентов. По умолчанию 0 для каждого.

Properties

СвойствоТипПо умолчаниюОписание
xnumber0Компонент x.
ynumber0Компонент y.
znumber0Компонент z.

Methods

.clone()

Возвращает новый Vector3 с теми же значениями x, y, z.

.copy( v )

Копирует значения v в этот вектор и возвращает self.

.set( x, y, z )

Устанавливает компоненты x, y, z и возвращает self.

.equals( v )

Возвращает true, если этот вектор и v имеют идентичные компоненты x, y, z.

.length()

Возвращает евклидову длину этого вектора.

.lengthSq()

Возвращает квадрат длины этого вектора. Быстрее, чем .length(), когда сравниваются только величины.

.distanceTo( v )

Возвращает евклидово расстояние между этим вектором и v.

.distanceToSquared( v )

Возвращает квадрат расстояния между этим вектором и v.

.dot( v )

Возвращает скалярное произведение этого вектора и v.

.applyMatrix4( m )

Преобразует этот вектор матрицей 4x4 m (возвращает новый вектор), рассматривая его как точку (применяется трансляция).

.applyQuaternion( q )

Поворачивает этот вектор кватернионом q, возвращая новый вектор.

.transformDirection( m )

Преобразует направление этого вектора матрицей m и нормализует результат, без применения трансляции. Возвращает новый вектор.

Differences from three.js

  • Vector3 предоставляет два параллельных семейства методов вместо единого мутирующего API three.js. Иммутабельная группа (add, sub, mul, div, normalize, lerp, min, max, clamp, floor, ceil, round и их скалярные варианты) всегда возвращает новый Vector3 и не трогает self. Мутирующая, совместимая с three.js группа — addV, subV, normalizeSelf, lerpSelf, minSelf, maxSelf, clampSelf, floorSelf, ceilSelf, roundSelf — изменяет self на месте и возвращает self, соответствуя поведению add/sub/normalize/и т.д. в three.js.
  • Обе группы существуют параллельно, чтобы места вызова могли выбрать подходящий стиль: иммутабельная группа избегает багов алиасинга, частых в горячих циклах, а группа *Self позволяет портированному коду three.js и критичным к производительности участкам мутировать без аллокаций.

.add( v )

Возвращает новый вектор: this + v. Не изменяет self.

.sub( v )

Возвращает новый вектор: this - v. Не изменяет self.

.mul( v )

Возвращает новый вектор: покомпонентное this * v. Не изменяет self.

.div( v )

Возвращает новый вектор: покомпонентное this / v. Не изменяет self.

.addScalar( s )

Возвращает новый вектор с s, добавленным к каждому компоненту.

.subScalar( s )

Возвращает новый вектор с s, вычтенным из каждого компонента.

.mulScalar( s )

Возвращает новый вектор с каждым компонентом, умноженным на s.

.divScalar( s )

Возвращает новый вектор с каждым компонентом, делённым на s.

.negate()

Возвращает новый вектор с каждым компонентом, взятым с обратным знаком.

.normalize()

Возвращает новый вектор единичной длины в том же направлении. Если длина равна нулю, возвращает нулевой вектор.

.lerp( v, t )

Возвращает новый вектор, линейно интерполированный между this и v по t.

.min( v )

Возвращает новый вектор с покомпонентным минимумом this и v.

.max( v )

Возвращает новый вектор с покомпонентным максимумом this и v.

.clamp( min, max )

Возвращает новый вектор с каждым компонентом, ограниченным между соответствующими компонентами min и max.

.floor()

Возвращает новый вектор с каждым компонентом, округлённым вниз.

.ceil()

Возвращает новый вектор с каждым компонентом, округлённым вверх.

.round()

Возвращает новый вектор с каждым компонентом, округлённым до ближайшего целого.

.cross( v )

Возвращает новый вектор: векторное произведение this и v.

.addV( v )

Прибавляет v к этому вектору на месте. Возвращает self.

.subV( v )

Вычитает v из этого вектора на месте. Возвращает self.

.normalizeSelf()

Нормализует этот вектор на месте. Возвращает self.

.lerpSelf( v, t )

Линейно интерполирует этот вектор к v по t, на месте. Возвращает self.

.minSelf( v )

Устанавливает каждый компонент в минимум себя и соответствующего компонента v, на месте. Возвращает self.

.maxSelf( v )

Устанавливает каждый компонент в максимум себя и соответствующего компонента v, на месте. Возвращает self.

.clampSelf( min, max )

Ограничивает каждый компонент между min и max, на месте. Возвращает self.

.floorSelf()

Округляет вниз каждый компонент на месте. Возвращает self.

.ceilSelf()

Округляет вверх каждый компонент на месте. Возвращает self.

.roundSelf()

Округляет каждый компонент на месте. Возвращает self.
