Sprite

Extends Mesh, inherits its API. A flat quad whose world rotation the renderer overwrites every frame to face the camera — position and scale stay under your own transform, like any Mesh.

local sprite = Sprite:new(MeshStandardMaterial:new{ map = texture })
sprite.position:set(0, 1.2, 0)
sprite.scale:set(0.5, 0.5, 1)
scene:add(sprite)

Constructor

Sprite(material)

Geometry is a shared unit PlaneGeometry (1x1, lying in XY facing +Z), scaled per instance via .scale — every sprite in a scene reuses the same one. With no rotation applied it already faces the camera along -Z the way three.js sprites do.

Properties

PropertyTypeDefaultDescription
center{x, y}{0.5, 0.5}three.js's pivot field, kept for parity — not read by the quad above.

Otherwise inherits every Mesh property.

Methods

.isSprite()

Returns true.

Differences from three.js

  • Billboarding happens in the renderer, not the object. WebGLRenderer checks .isSprite() during its scene walk and overwrites the sprite's world rotation with the camera's, matching three.js's effective behaviour without a dedicated SpriteMaterial/raycast path.
  • Takes any Material (typically MeshStandardMaterial with a map) rather than three.js's dedicated SpriteMaterial.

Sprite

Наследует Mesh, наследует её API. Плоский квад, чей мировой поворот рендерер перезаписывает каждый кадр, чтобы он смотрел на камеру — позиция и масштаб остаются под вашим собственным transform, как у любого Mesh.

local sprite = Sprite:new(MeshStandardMaterial:new{ map = texture })
sprite.position:set(0, 1.2, 0)
sprite.scale:set(0.5, 0.5, 1)
scene:add(sprite)

Constructor

Sprite(material)

Геометрия — общий единичный PlaneGeometry (1x1, лежит в XY, смотрит в +Z), масштабируемый на каждый инстанс через .scale — все спрайты сцены переиспользуют один и тот же. Без поворота он уже смотрит на камеру вдоль -Z, как спрайты в three.js.

Properties

СвойствоТипПо умолчаниюОписание
center{x, y}{0.5, 0.5}Поле pivot из three.js, оставлено для паритета — квадом выше не читается.

В остальном наследует все свойства Mesh.

Methods

.isSprite()

Возвращает true.

Differences from three.js

  • Billboarding происходит в рендерере, а не в объекте. WebGLRenderer проверяет .isSprite() во время обхода сцены и перезаписывает мировой поворот спрайта поворотом камеры, повторяя эффективное поведение three.js без отдельного SpriteMaterial/raycast-пути.
  • Принимает любой Material (обычно MeshStandardMaterial с map), а не отдельный SpriteMaterial из three.js.
