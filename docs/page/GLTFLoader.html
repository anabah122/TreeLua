GLTFLoader

Loads glTF 2.0 / GLB files. Extends Loader.

local loader = GLTFLoader:new()
loader:load("assets/model/model3dtest.glb", function(gltf)
    scene:add(gltf.scene)
    mixer:clipAction(gltf.animations[1]):play()
end)

.setTextures(enabled)

Toggles whether textures are loaded and sampled onto materials.

.setAnisotropy(value)

.load(url, onLoad, onProgress, onError)

Reads and parses the file synchronously, then returns { scene, animations, asset, userData }:

FieldDescription
sceneA Group named "gltf" containing the file's meshes (Mesh or SkinnedMesh).
animationsArray of AnimationClip.
assetThe glTF file's asset JSON block, if present.
userData.importerThe raw importer output, for anything the facade does not cover.

onLoad and onProgress are called immediately (reads are synchronous), and the result is also returned directly, so both the callback and the return-value spelling work. On failure, onError is called if given, otherwise the error propagates.

.loadSync(url)

Equivalent to load(url) with no callbacks — three.js has no synchronous loader, so this spelling exists for callers who want to make that explicit.

Differences from three.js

  • Synchronous. three.js's GLTFLoader fetches over the network and calls back asynchronously; this one reads from disk and calls back (and returns) immediately.
  • Returns a plain { scene, animations, asset, userData } table rather than three.js's full GLTF result object — no parser, cameras or scenes array.

GLTFLoader

Загружает файлы glTF 2.0 / GLB. Наследуется от Loader.

local loader = GLTFLoader:new()
loader:load("assets/model/model3dtest.glb", function(gltf)
    scene:add(gltf.scene)
    mixer:clipAction(gltf.animations[1]):play()
end)

.setAnisotropy(value)

.load(url, onLoad, onProgress, onError)

Синхронно читает и парсит файл, затем возвращает { scene, animations, asset, userData }:

ПолеОписание
sceneGroup с именем "gltf", содержащая меши файла (Mesh или SkinnedMesh).
animationsМассив AnimationClip.
assetБлок JSON asset из файла glTF, если он присутствует.
userData.importerСырой вывод импортера — для всего, что не покрывает фасад.

onLoad и onProgress вызываются немедленно (чтение синхронное), а результат также возвращается напрямую, так что работают оба варианта — и через колбэк, и через возвращаемое значение. При ошибке вызывается onError, если он задан, иначе ошибка пробрасывается дальше.

.loadSync(url)

Эквивалентно load(url) без колбэков — в three.js нет синхронного загрузчика, поэтому такое написание существует для тех, кто хочет сделать это явным.

Differences from three.js

  • Синхронность. GLTFLoader в three.js загружает данные по сети и вызывает колбэк асинхронно; этот же читает с диска и вызывает колбэк (а также возвращает результат) немедленно.
  • Возвращает простую таблицу { scene, animations, asset, userData } вместо полного объекта результата GLTF из three.js — нет parser, cameras или массива scenes.
