Mesh

Drawable geometry plus a material. Extends Object3D and inherits its full API. The importers already produce a love.Mesh per primitive, so .geometry here is a thin holder around that object rather than a vertex-buffer abstraction: the engine's job is to hand it to love.graphics.draw with the right uniforms set, which is what the renderer does by reading the fields below.

local mesh = Mesh:new(geometry, material)
scene:add(mesh)

Constructor

Mesh(geometry, material)

Properties

PropertyTypeDefaultDescription
geometryBufferGeometry—
materialMaterial—
skintablenilSet by the loaders for skinned primitives; see SkinnedMesh.
bindShapeMatrixMatrix4nilStraight off the importer entry. A mesh carrying a skin is drawn with the bone palette; one without is drawn rigid.

Otherwise inherits all of Object3D's properties.

Methods

.isMesh()

Returns true.

.copy(source, recursive)

Extends Object3D.copy. geometry and material are shared, as in three.js: cloning a mesh gives a second transform over the same buffers, not a second copy of the data.

All other methods come from Object3D.

Mesh

Отрисовываемая геометрия плюс материал. Наследует Object3D и получает весь его API. Импортёры уже производят love.Mesh для каждого примитива, поэтому .geometry здесь — тонкий держатель вокруг этого объекта, а не абстракция вершинного буфера: задача движка — передать его в love.graphics.draw с правильно выставленными uniform'ами, что и делает рендерер, читая поля ниже.

local mesh = Mesh:new(geometry, material)
scene:add(mesh)

Constructor

Mesh(geometry, material)

Properties

СвойствоТипПо умолчаниюОписание
geometryBufferGeometry—
materialMaterial—
skintablenilУстанавливается загрузчиками для скиннированных примитивов; см. SkinnedMesh.
bindShapeMatrixMatrix4nilПрямо из записи импортёра. Меш с скином рисуется с палитрой костей; без него — жёстко (rigid).

В остальном наследует все свойства Object3D.

Methods

.isMesh()

Возвращает true.

.copy(source, recursive)

Расширяет Object3D.copy. geometry и material используются совместно (общие), как в three.js: клонирование меша даёт второй трансформ поверх тех же буферов, а не вторую копию данных.

Все остальные методы приходят из Object3D.
