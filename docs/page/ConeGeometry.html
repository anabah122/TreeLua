ConeGeometry

A cone, defined the same way three.js defines it: a CylinderGeometry with its top radius pinned to 0. Everything else — segments, openEnded, theta range — passes straight through.

Constructor

ConeGeometry(radius, height, radialSegments, heightSegments, openEnded, thetaStart, thetaLength)

radius/height default to 1. Remaining arguments forward to CylinderGeometry unchanged.

Properties

PropertyTypeDefaultDescription
parameterstable—The underlying CylinderGeometry's parameters, with radius added.
typestring"ConeGeometry"Overridden after construction (the underlying object is a CylinderGeometry).

Methods

No methods beyond the constructor and what BufferGeometry provides.

Differences from three.js

  • Implemented as a thin wrapper: it calls CylinderGeometry:new(0, radius, height, ...) and then overwrites .type/.name/.parameters.radius. The resulting object still carries a radiusTop/radiusBottom pair in .parameters (inherited from the cylinder) in addition to the three.js-shaped radius field.

ConeGeometry

Конус, определённый так же, как его определяет three.js: CylinderGeometry с верхним радиусом, зафиксированным на 0. Всё остальное — сегменты, openEnded, диапазон theta — передаётся без изменений.

Constructor

ConeGeometry(radius, height, radialSegments, heightSegments, openEnded, thetaStart, thetaLength)

radius/height по умолчанию 1. Остальные аргументы передаются в CylinderGeometry без изменений.

Properties

СвойствоТипПо умолчаниюОписание
parameterstable—Параметры лежащего в основе CylinderGeometry, с добавленным radius.
typestring"ConeGeometry"Переопределяется после конструирования (объект в основе — CylinderGeometry).

Methods

Нет методов, кроме конструктора и того, что предоставляет BufferGeometry.

Differences from three.js

  • Реализован как тонкая обёртка: вызывает CylinderGeometry:new(0, radius, height, ...), а затем перезаписывает .type/.name/.parameters.radius. Результирующий объект по-прежнему несёт пару radiusTop/radiusBottom в .parameters (унаследованную от цилиндра) в дополнение к полю radius в стиле three.js.
