CylinderGeometry

A cylinder (or, with a zero top radius, a cone) built from a tapered side wall plus two optional caps. ConeGeometry is this generator with radiusTop pinned to 0.

Constructor

CylinderGeometry(radiusTop, radiusBottom, height, radialSegments, heightSegments, openEnded, thetaStart, thetaLength)

radiusTop/radiusBottom/height default to 1. radialSegments defaults to 32 (minimum 3), heightSegments defaults to 1. openEnded defaults to false (caps included). thetaStart defaults to 0, thetaLength to 2π.

Properties

PropertyTypeDefaultDescription
parameterstable—{ radiusTop, radiusBottom, height, radialSegments, heightSegments, openEnded, thetaStart, thetaLength } as resolved by the constructor.

Methods

No methods beyond the constructor and what BufferGeometry provides.

Differences from three.js

  • Built through the shared three/geometries/build.lua helper, which forces convex-about-origin outward winding. A closed cylinder is convex, so this is transparent; the tip row of a degenerate cone (radiusTop or radiusBottom of 0) is skipped by the generator, and the cap index order is arbitrary since the helper reorients it regardless.

TreeLua / Geometries

CylinderGeometry

Цилиндр (или, при нулевом верхнем радиусе, конус), построенный из сужающейся боковой стенки плюс двух опциональных крышек. ConeGeometry — это тот же генератор с radiusTop, зафиксированным на 0.

Constructor

CylinderGeometry(radiusTop, radiusBottom, height, radialSegments, heightSegments, openEnded, thetaStart, thetaLength)

radiusTop/radiusBottom/height по умолчанию 1. radialSegments по умолчанию 32 (минимум 3), heightSegments по умолчанию 1. openEnded по умолчанию false (крышки включены). thetaStart по умолчанию 0, thetaLength — 2π.

Properties

СвойствоТипПо умолчаниюОписание
parameterstable—{ radiusTop, radiusBottom, height, radialSegments, heightSegments, openEnded, thetaStart, thetaLength }, как разрешено конструктором.

Methods

Нет методов, кроме конструктора и того, что предоставляет BufferGeometry.

Differences from three.js

  • Строится через общий хелпер three/geometries/build.lua, который принудительно задаёт выпуклый внешний winding относительно начала координат. Замкнутый цилиндр выпуклый, поэтому это не влияет на результат; крайний ряд вырожденного конуса (radiusTop или radiusBottom равный 0) пропускается генератором, а порядок индексов крышки произволен, поскольку хелпер в любом случае переориентирует его.

Source: three/geometries/CylinderGeometry.lua
