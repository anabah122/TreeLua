WebGLRenderer

Draws a Scene from a Camera into the LÖVE window. The name is kept from three.js so the docs read across, but there is no WebGL here — love.graphics does the work, and this class is the only one that touches it. Shaders come in two variants, static and skinned, assembled by shader/init.lua; draws are grouped so each variant is bound once per frame.

Constructor

WebGLRenderer(params)

params is an optional table:

PropertyTypeDefaultDescription
shaderlove.ShadernilForces one shader for every draw instead of picking the static/skinned variant per mesh.
autoClearbooleantrueWhether render() clears the screen itself.
clearColornumber0x171a21Hex color passed to Color:new().
clearAlphanumber1
sortObjectsbooleantrueSort each draw bucket by render order / transparency / depth.
autoUpdateScenebooleantrueWhether render() calls scene:updateMatrixWorld() itself.
diffuseWrapnumber0.25How far the diffuse term wraps past the terminator; 0 is physically strict, 1 is flat. Compensates for having only one light and no global illumination.
frustumCullingbooleantruethree.js flag of the same name; off draws everything.

Properties

PropertyTypeDefaultDescription
typestring"WebGLRenderer"
info.rendertable—calls, triangles, meshes, culled, shaderSwaps; reset and refilled every render() call.

Plus the constructor params above, all stored as same-named fields (shader, autoClear, clearColor, clearAlpha, sortObjects, autoUpdateScene, diffuseWrap, frustumCulling) and mutable after construction.

Methods

.isWebGLRenderer()

Returns true.

.setClearColor(color, alpha)

alpha is optional; when omitted the current clearAlpha is kept.

.getSize()

Returns love.graphics.getWidth(), love.graphics.getHeight() — the renderer does not own a canvas size of its own.

.setSize(width, height, camera)

LÖVE owns the window, so this does not resize anything — it only keeps a perspective camera's aspect honest. Call it from love.resize. camera is optional; if given and it has a setAspect method, width / height is applied to it.

.clear(scene)

Clears the screen to scene.background if set, otherwise to clearColor/clearAlpha. Called automatically by render() when autoClear is true.

.render(scene, camera)

Updates world matrices (unless autoUpdateScene is false, or for the camera when it has a parent), clears if autoClear, then walks the scene once to collect drawable meshes and lights, frustum-culls, sorts, and draws. Draw order is static meshes first, then skinned, so each shader program is bound once. Restores default shader, cull mode and depth mode before returning.

.dispose()

Clears shader and the internal shader-variant table.

Differences from three.js

  • Lighting is one directional light plus one ambient term. If the scene has several DirectionalLights, the brightest is used and the rest are ignored (a warning is printed once). Multiple AmbientLights are summed rather than picking one.
  • No shadow mapping. castShadow / receiveShadow on objects and lights are not read.
  • Skinned meshes are capped at WebGLRenderer.MAX_BONES (128 bones), matching the shader's uniform array size. A longer skeleton is truncated and reported once per mesh via print.
  • Skinned meshes are exempt from frustum culling: their bounding sphere describes the bind pose, which an animation routinely leaves, so culling against it would pop a character out of view mid-stride.
  • No WebGL/canvas — setSize does not resize anything; LÖVE owns the window.

WebGLRenderer

Рисует Scene из Camera в окно LÖVE. Имя сохранено от three.js, чтобы документация читалась параллельно, но никакого WebGL здесь нет — всю работу делает love.graphics, и этот класс — единственный, кто его касается. Шейдеры бывают двух вариантов, статический и скиннинговый, собираются shader/init.lua; отрисовки группируются так, чтобы каждый вариант привязывался один раз за кадр.

Плюс параметры конструктора выше, все хранятся как поля с теми же именами (shader, autoClear, clearColor, clearAlpha, sortObjects, autoUpdateScene, diffuseWrap, frustumCulling) и изменяемы после создания.

Methods

.isWebGLRenderer()

Возвращает true.

.setClearColor(color, alpha)

alpha необязателен; если не указан, сохраняется текущий clearAlpha.

.getSize()

Возвращает love.graphics.getWidth(), love.graphics.getHeight() — рендерер не владеет собственным размером канваса.

.setSize(width, height, camera)

Окном владеет LÖVE, поэтому это ничего не меняет в размерах — метод только поддерживает честный aspect у перспективной камеры. Вызывайте его из love.resize. camera необязательна; если передана и у неё есть метод setAspect, к ней применяется width / height.

.clear(scene)

Очищает экран в scene.background, если он задан, иначе в clearColor/clearAlpha. Вызывается автоматически из render(), когда autoClear истинен.

.render(scene, camera)

Обновляет мировые матрицы (если autoUpdateScene не ложный, а также для камеры, если у неё есть родитель), очищает экран, если autoClear, затем один раз обходит сцену, собирая отрисовываемые меши и источники света, отсекает по frustum, сортирует и рисует. Порядок отрисовки: сначала статические меши, затем скиннинговые, чтобы каждая шейдерная программа привязывалась один раз. Перед возвратом восстанавливает шейдер по умолчанию, режим отсечения граней и режим глубины.

.dispose()

Очищает shader и внутреннюю таблицу вариантов шейдеров.

Differences from three.js

  • Освещение — один направленный источник плюс один ambient-член. Если в сцене несколько DirectionalLight, используется самый яркий, остальные игнорируются (предупреждение печатается один раз). Несколько AmbientLight суммируются, а не выбирается один.
  • Нет карт теней. castShadow / receiveShadow у объектов и источников света не читаются.
  • Скиннинговые меши ограничены WebGLRenderer.MAX_BONES (128 костей), что соответствует размеру uniform-массива шейдера. Более длинный скелет обрезается, и это сообщается один раз на меш через print.
  • Скиннинговые меши не подвергаются frustum culling: их ограничивающая сфера описывает bind pose, из которой анимация обычно выходит, поэтому отсечение по ней могло бы выкидывать персонажа из вида посреди движения.
  • Нет WebGL/canvas — setSize ничего не меняет в размерах; окном владеет LÖVE.
