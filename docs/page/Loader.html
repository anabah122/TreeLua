TreeLua / Loaders

Loader

Base class for the format loaders (GLTFLoader, ColladaLoader, TextureLoader). Holds the setPath/resolveURL path-prefixing convention shared with three.js, plus _assemble, the shared routine that turns an importer's flat primitive list into a { scene, animations } facade. Not used directly.

Constructor

Loader()

Sets type = "Loader" and path = "".

Properties

PropertyTypeDefaultDescription
typestring"Loader"Set by extend() for subclasses.
pathstring""Prefix joined to every URL passed to load().

Methods

.setPath(path)

Sets the prefix used by resolveURL.

.resolveURL(url)

Returns self.path .. url, or url unchanged if no path is set.

Differences from three.js

  • extend(typeName) is TreeLua's subclassing hook and has no three.js equivalent.
  • Does not implement three.js's LoadingManager, crossOrigin, withCredentials, requestHeader or MIME-type options — there is no network layer to configure.

Source: three/loaders/Loader.lua

TreeLua / Loaders

Loader

Базовый класс для загрузчиков форматов (GLTFLoader, ColladaLoader, TextureLoader). Хранит конвенцию setPath/resolveURL для префиксов путей, общую с three.js, а также _assemble — общую процедуру, которая превращает плоский список примитивов импортёра в фасад { scene, animations }. Напрямую не используется.

Constructor

Loader()

Устанавливает type = "Loader" и path = "".

Properties

СвойствоТипПо умолчаниюОписание
typestring"Loader"Устанавливается extend() для подклассов.
pathstring""Префикс, присоединяемый к каждому URL, переданному в load().

Methods

.setPath(path)

Устанавливает префикс, используемый в resolveURL.

.resolveURL(url)

Возвращает self.path .. url, либо url без изменений, если путь не задан.

Differences from three.js

  • extend(typeName) — хук наследования TreeLua и не имеет аналога в three.js.
  • Не реализует LoadingManager, crossOrigin, withCredentials, requestHeader и опции MIME-типа из three.js — сетевого слоя, который нужно было бы настраивать, здесь нет.
