Sphere

A bounding sphere, defined by a center and radius. An empty sphere has radius < 0, so a fresh sphere grows correctly under expandByPoint without a separate empty flag.

Constructor

Sphere( center, radius )

center — a Vector3, cloned in, defaults to the origin. radius defaults to -1 (empty).

Properties

PropertyTypeDefaultDescription
centerVector3(0,0,0)
radiusnumber-1Negative means empty.

Methods

.isSphere()

Returns true. Type-check facade.

.set( center, radius )

Sets center (copied) and radius. Returns self.

.clone()

Returns a new Sphere with the same center and radius.

.copy( sphere )

Copies sphere's center and radius into this sphere. Returns self.

.isEmpty()

Returns true if radius is negative.

.makeEmpty()

Resets this sphere to the empty state (center at origin, radius -1). Returns self.

.containsPoint( point )

Returns true if point lies within this sphere.

.distanceToPoint( point )

Returns the signed distance from point to the sphere's surface (negative if inside).

.intersectsSphere( sphere )

Returns true if this sphere and sphere overlap.

.intersectsBox( box )

Returns true if this sphere overlaps box.

.expandByPoint( point )

Grows this sphere just enough to include point, recentring so the far side of the sphere does not balloon outward. Returns self.

.getBoundingBox( target )

Writes this sphere's axis-aligned bounding box into target (a Box3, created if omitted) and returns it.

.setFromPoints( points, optionalCenter )

Sets this sphere to the minimal sphere (around optionalCenter, or the bounding box center if omitted) that encloses every point. Returns self.

.applyMatrix4( m )

Transforms this sphere by matrix m, in place. Since a non-uniform scale cannot keep the shape a true sphere, the radius is scaled by the largest of the three axis scales, so the result always encloses the true transformed shape. Returns self.

.translate( offset )

Moves this sphere's center by offset, in place. Returns self.

.equals( sphere )

Returns true if this sphere and sphere have equal center and radius.

Differences from three.js

  • .applyMatrix4 approximates non-uniform scale by taking the largest axis scale rather than three.js's exact approach of transforming via the box, so the result is a conservative (never-too-small) enclosing sphere rather than a tight fit.

Sphere

Ограничивающая сфера, заданная центром и радиусом. У пустой сферы radius < 0, поэтому свежесозданная сфера корректно растёт при expandByPoint без отдельного флага пустоты.

Constructor

Sphere( center, radius )

center — Vector3, клонируется при передаче, по умолчанию — начало координат. radius по умолчанию -1 (пусто).

Properties

СвойствоТипПо умолчаниюОписание
centerVector3(0,0,0)
radiusnumber-1Отрицательное значение означает пустоту.

Methods

.isSphere()

Возвращает true. Фасад проверки типа.

.set( center, radius )

Устанавливает center (копируется) и radius. Возвращает self.

.clone()

Возвращает новую Sphere с тем же центром и радиусом.

.copy( sphere )

Копирует center и radius из sphere в эту сферу. Возвращает self.

.isEmpty()

Возвращает true, если radius отрицателен.

.makeEmpty()

Сбрасывает эту сферу в пустое состояние (центр в начале координат, radius -1). Возвращает self.

.containsPoint( point )

Возвращает true, если point лежит внутри этой сферы.

.distanceToPoint( point )

Возвращает знаковое расстояние от point до поверхности сферы (отрицательное, если точка внутри).

.intersectsSphere( sphere )

Возвращает true, если эта сфера и sphere пересекаются.

.intersectsBox( box )

Возвращает true, если эта сфера пересекается с box.

.expandByPoint( point )

Увеличивает эту сферу ровно настолько, чтобы включить point, пересчитывая центр так, чтобы дальняя сторона сферы не раздувалась наружу. Возвращает self.

.getBoundingBox( target )

Записывает выровненный по осям ограничивающий параллелепипед этой сферы в target (Box3, создаётся, если не передан) и возвращает его.

.setFromPoints( points, optionalCenter )

Устанавливает эту сферу как минимальную сферу (вокруг optionalCenter, либо центра ограничивающего параллелепипеда, если не передан), охватывающую все точки. Возвращает self.

.applyMatrix4( m )

Трансформирует эту сферу матрицей m на месте. Поскольку неравномерный масштаб не может сохранить форму настоящей сферы, радиус масштабируется по наибольшему из трёх осевых масштабов, так что результат всегда охватывает истинную трансформированную форму. Возвращает self.

.translate( offset )

Сдвигает центр этой сферы на offset, на месте. Возвращает self.

.equals( sphere )

Возвращает true, если у этой сферы и sphere равны center и radius.

Differences from three.js

  • .applyMatrix4 приближает неравномерный масштаб, беря наибольший осевой масштаб, вместо точного подхода three.js, трансформирующего через параллелепипед, поэтому результат — консервативная (никогда не слишком маленькая) охватывающая сфера, а не точная подгонка.
