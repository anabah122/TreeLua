DirectionalLight

Extends Light, inherits its API. Parallel rays, like the sun. Direction is not a stored field: three.js derives it from the light's position relative to .target, whose default sits at the origin, and this engine does the same. Moving the light aims it; distance does nothing, since the rays are parallel.

local sun = DirectionalLight:new(0xfff5ec, 1)
sun.position:set(-0.4, 1.0, 0.6)
scene:add(sun)

Constructor

DirectionalLight(color, intensity)

Same defaults as Light. Additionally sets .position to (0, 1, 0) and creates a fresh Object3D as .target, matching three.js's default of a light at (0,1,0) looking at the origin.

Properties

PropertyTypeDefaultDescription
targetObject3Dnew Object3D at originNot added to the scene automatically, matching three.js — add it yourself if you move it and want that reflected in the world matrix used for direction.
castShadowbooleanfalseOpts this light into the renderer's shadow pass. Off by default so a scene with no shadows never pays for the second pass.
shadow.mapSizenumber1024Width/height of the (square) shadow map canvas.
shadow.biasnumber0.003Depth offset subtracted before the comparison, against shadow acne.
shadow.cameraOrthographicCamera(-10,10,10,-10,0.1,50)Frustum the shadow map is rendered from; widen it to cover the scene, repositioned each frame by .updateShadowCamera.

Inherits color and intensity from Light. See WebGLRenderer for shadowTarget and TL.settings.shadowSoftness, and Object3D's castShadow/receiveShadow for the per-mesh side.

Methods

.isDirectionalLight()

Returns true.

.direction(target)

Unit vector along which the light travels: from the light's world position toward .target's world position — the same vector three.js computes internally when filling its light uniforms. Updates both world matrices first. A light sitting exactly on its target has no direction; rather than hand back a zero vector, it returns (0, -1, 0).

.updateShadowCamera(target)

Points .shadow.camera (an OrthographicCamera — parallel rays need no perspective) down this light's direction, centred on world-space target. Called by WebGLRenderer before the shadow pass; not usually called by hand.

.copy(source, recursive)

Differences from three.js

  • Only one directional light is sampled. The bundled shader takes exactly one DirectionalLight plus one ambient term as uniforms. A scene may contain several DirectionalLights, but the renderer picks a single one to send — additional lights are not summed or otherwise blended, and do not silently disappear from the graph, only from the lighting calculation.
  • A light exactly coincident with its target returns (0, -1, 0) from .direction() rather than a zero vector, avoiding a degenerate normalize.

TreeLua / Lights

DirectionalLight

Наследует Light, наследует её API. Параллельные лучи, как у солнца. Направление не хранится как поле: three.js выводит его из позиции источника относительно .target, чьё значение по умолчанию — начало координат, и этот движок делает то же самое. Перемещение источника наводит его; расстояние не играет роли, поскольку лучи параллельны.

local sun = DirectionalLight:new(0xfff5ec, 1)
sun.position:set(-0.4, 1.0, 0.6)
scene:add(sun)

Constructor

DirectionalLight(color, intensity)

Те же значения по умолчанию, что и у Light. Дополнительно устанавливает .position в (0, 1, 0) и создаёт свежий Object3D как .target, соответствуя умолчанию three.js — источник в (0,1,0), смотрящий на начало координат.

Наследует color и intensity от Light. См. WebGLRenderer про shadowTarget и TL.settings.shadowSoftness, а также castShadow/ receiveShadow у Object3D для стороны меша.

Methods

.isDirectionalLight()

Возвращает true.

.direction(target)

Единичный вектор, вдоль которого распространяется свет: от мировой позиции источника к мировой позиции .target — тот же вектор, что three.js вычисляет внутренне при заполнении своих uniform источников света. Сначала обновляет обе мировые матрицы. Источник, находящийся точно на цели, не имеет направления; вместо возврата нулевого вектора возвращается (0, -1, 0).

.updateShadowCamera(target)

Направляет .shadow.camera (OrthographicCamera — параллельным лучам перспектива не нужна) вдоль направления этого света, центрируя на мировой точке target. Вызывается WebGLRenderer перед теневым проходом; вручную обычно не нужен.

.copy(source, recursive)

Differences from three.js

  • Сэмплируется только один направленный источник света. Встроенный шейдер принимает как uniform ровно один DirectionalLight плюс один ambient-член. Сцена может содержать несколько DirectionalLight, но рендерер выбирает для отправки только один — дополнительные источники не суммируются и никак иначе не смешиваются, и не исчезают из графа незаметно, а лишь из расчёта освещения.
  • Источник, находящийся точно на месте своей цели, возвращает из .direction() (0, -1, 0) вместо нулевого вектора, избегая вырожденной нормализации.
