ColladaLoader

Loads Collada (.dae) files. Extends Loader. The importer folds the file's <unit meter="..."> into the root transform at load time, so a Collada scene arrives in metres like a glTF one and needs no scale fudge from the caller.

local loader = ColladaLoader:new()
local dae = loader:load("assets/model/Dancing.dae")
scene:add(dae.scene)

.load(url, onLoad, onProgress, onError)

Reads and parses the file synchronously, then returns { scene, animations, upAxis, userData }:

FieldDescription
sceneA Group named "collada" containing the file's meshes.
animationsArray of AnimationClip.
upAxisThe file's declared up axis, surfaced from the importer.
userData.importerThe raw importer output.

onLoad and onProgress fire immediately, and the result is also returned directly. On failure, onError is called if given, otherwise the error propagates.

.loadSync(url)

Equivalent to load(url) with no callbacks.

Differences from three.js

  • Synchronous, like GLTFLoader — reads from disk and returns immediately rather than fetching over the network.
  • Returns { scene, animations, upAxis, userData } — three.js's ColladaLoader result also includes kinematics and library, which are not exposed here.

ColladaLoader

Загружает файлы Collada (.dae). Наследуется от Loader. Импортёр складывает объявленный в файле <unit meter="..."> в корневой трансформ уже во время загрузки, поэтому сцена Collada приходит в метрах, как и glTF-сцена, и не требует ручной подгонки масштаба со стороны вызывающего кода.

local loader = ColladaLoader:new()
local dae = loader:load("assets/model/Dancing.dae")
scene:add(dae.scene)

.load(url, onLoad, onProgress, onError)

Читает и парсит файл синхронно, затем возвращает { scene, animations, upAxis, userData }:

ПолеОписание

onLoad и onProgress вызываются немедленно, и результат также возвращается напрямую. При ошибке вызывается onError, если он задан, иначе ошибка распространяется дальше.

.loadSync(url)

Эквивалентно load(url) без коллбэков.

Differences from three.js

  • Синхронный, как и GLTFLoader — читает с диска и возвращает результат немедленно, а не загружает по сети.
  • Возвращает { scene, animations, upAxis, userData } — результат ColladaLoader в three.js также включает kinematics и library, которые здесь не предоставляются.
