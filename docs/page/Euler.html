TreeLua / Math

Euler

Three axis angles (in radians) plus the order they are applied in. Exists because object.rotation.x = ...-style edits are more common than building quaternions by hand; internally, nothing consumes an Euler directly — Object3D converts it to a quaternion, which is what the importers, skinning, and Matrix4:compose all speak.

Constructor

Euler( x, y, z, order )

x, y, z default to 0. order defaults to "XYZ" (Euler.DEFAULT_ORDER).

Properties

Methods

.set( x, y, z, order )

Sets the angles and, optionally, the order. Returns self.

.clone()

Returns a new Euler with the same angles and order.

.copy( e )

Copies e's angles and order into this Euler. Returns self.

.equals( e )

Returns true if this Euler and e have identical angles and order.

.setFromRotationMatrix( m, order )

Extracts angles from a pure rotation matrix m in the given order (defaults to this Euler's current order). Clamps each asin argument to [-1, 1] to avoid NaN from accumulated floating-point drift, and handles gimbal lock by pinning z to 0. Returns self.

.setFromQuaternion( q, order )

Sets this Euler from quaternion q, by way of Matrix4:makeRotationFromQuaternion and setFromRotationMatrix. Returns self.

.setFromVector3( v, order )

Sets x, y, z from v's components. Returns self.

.reorder( newOrder )

Re-derives the angles for newOrder while preserving the same net rotation, by round-tripping through a Quaternion. Returns self.

.toArray()

Returns {x, y, z, order}.

.fromArray( array, offset )

Sets x, y, z, and (if present) order from array starting at offset. Returns self.

Differences from three.js

  • .setFromRotationMatrix reads matrix elements assuming TreeLua's row-major Matrix4 storage, so the element indices used differ from three.js's column-major version even though the underlying trigonometry matches.

TreeLua / Math

Euler

Три угла поворота вокруг осей (в радианах) плюс порядок, в котором они применяются. Существует потому, что правки вида object.rotation.x = ... встречаются чаще, чем построение кватернионов вручную; внутри движка Euler напрямую не используется — Object3D преобразует его в кватернион, а именно с кватернионами работают импортёры, скиннинг и Matrix4:compose.

Constructor

Euler( x, y, z, order )

x, y, z по умолчанию равны 0. order по умолчанию — "XYZ" (Euler.DEFAULT_ORDER).

Properties

СвойствоТипПо умолчаниюОписание
xnumber0
ynumber0
znumber0
orderstring"XYZ"Одно из "XYZ", "YXZ", "ZXY", "ZYX", "YZX", "XZY".

Methods

.set( x, y, z, order )

Устанавливает углы и, опционально, порядок. Возвращает self.

.clone()

Возвращает новый Euler с теми же углами и порядком.

.copy( e )

Копирует углы и порядок из e в этот Euler. Возвращает self.

.equals( e )

Возвращает true, если этот Euler и e имеют одинаковые углы и порядок.

.setFromRotationMatrix( m, order )

Извлекает углы из чистой матрицы вращения m в заданном порядке (по умолчанию — текущий порядок этого Euler). Ограничивает каждый аргумент asin диапазоном [-1, 1], чтобы избежать NaN из-за накопленной погрешности с плавающей точкой, и обрабатывает gimbal lock, фиксируя z в 0. Возвращает self.

.setFromQuaternion( q, order )

Устанавливает этот Euler из кватерниона q через Matrix4:makeRotationFromQuaternion и setFromRotationMatrix. Возвращает self.

.setFromVector3( v, order )

Устанавливает x, y, z из компонентов v. Возвращает self.

.reorder( newOrder )

Заново вычисляет углы для newOrder, сохраняя тот же итоговый поворот, проходя через Quaternion туда и обратно. Возвращает self.

.toArray()

Возвращает {x, y, z, order}.

.fromArray( array, offset )

Устанавливает x, y, z и (если присутствует) order из массива, начиная с offset. Возвращает self.

Differences from three.js

  • .setFromRotationMatrix читает элементы матрицы, исходя из построчного (row-major) хранения Matrix4 в TreeLua, поэтому используемые индексы элементов отличаются от версии three.js, хранящей матрицу по столбцам (column-major), хотя лежащая в основе тригонометрия совпадает.
