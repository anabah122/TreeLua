TextureLoader

Loads an image off disk as a love.Image. Extends Loader. There is no Texture class wrapping the result — love.Image already carries the filter and wrap state three.js keeps on Texture.

local tex = TextureLoader:new():load("assets/wood.png")
local m   = MeshStandardMaterial:new{ map = tex }

.load(url, onLoad, onProgress, onError)

Loads the image synchronously with love.graphics.newImage, applies filter, wrap and anisotropy, then returns the love.Image directly. onLoad and onProgress fire immediately. On failure, onError is called if given (and nil is returned either way); there is no throw-on-missing like the other loaders.

Differences from three.js

  • Synchronous — reads from disk and calls back (and returns) immediately rather than fetching over the network.
  • Returns a raw love.Image, not a three.js Texture — there is no wrapper object, so texture settings (filter, wrap, anisotropy) are configured on the loader before calling load, not on the result afterward.
  • On error, returns nil instead of throwing when no onError is given — the other loaders propagate the error.

TextureLoader

Загружает изображение с диска как love.Image. Наследуется от Loader. Класса Texture, оборачивающего результат, нет — love.Image уже несёт состояние фильтра и wrap, которое three.js хранит в Texture.

local tex = TextureLoader:new():load("assets/wood.png")
local m   = MeshStandardMaterial:new{ map = tex }

.setAnisotropy(value)

.load(url, onLoad, onProgress, onError)

Загружает изображение синхронно через love.graphics.newImage, применяет filter, wrap и anisotropy, затем возвращает сам love.Image напрямую. onLoad и onProgress срабатывают немедленно. При ошибке вызывается onError, если он задан (и в любом случае возвращается nil); в отличие от других загрузчиков, здесь нет броска исключения при отсутствии файла.

Differences from three.js

  • Синхронно — читает с диска и вызывает колбэк (и возвращает результат) немедленно, а не через сетевой запрос.
  • Возвращает сырой love.Image, а не three.js Texture — объекта-обёртки нет, поэтому настройки текстуры (filter, wrap, anisotropy) задаются на загрузчике до вызова load, а не на результате после.
  • При ошибке возвращает nil вместо выброса исключения, если onError не задан — остальные загрузчики пробрасывают ошибку дальше.
