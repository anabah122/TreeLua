OrbitControls

Orbits, dollies and pans a camera around a target point, with the same mouse bindings as three.js's OrbitControls: left-drag orbits, right-drag pans, the wheel dollies. Unlike FlyControls, this controller owns the camera's position outright — it derives it from target plus a spherical offset every update, so writing camera.position directly is overwritten on the next frame. Move target instead.

Constructor

OrbitControls.new(camera, params)

Seeds its spherical coordinates (radius/theta/phi) from wherever the camera already sits relative to target, so construction doesn't teleport it. params is an optional table overriding any of the properties below. Calls update(0) once before returning.

Methods

:update(dt)

Eases (if enableDamping) or snaps the current spherical coordinates toward their targets, then repositions the camera from target + the spherical offset and calls lookAt(target). Takes a dt, unlike three.js's version, specifically to drive the damping.

:mousepressed(x, y, button)

Records the drag mode: left button (1) starts rotate, right button (2) starts pan.

:mousereleased(x, y, button)

Clears the current drag mode.

:mousemoved(x, y, dx, dy)

Applies the drag delta according to the current mode (falling back to reading love.mouse.isDown live if mousepressed was never forwarded): rotate adjusts theta/phi, pan shifts target along the camera's right/up basis scaled by distance.

:wheelmoved(dy)

Scales the target radius by zoomSpeed or its inverse depending on scroll direction, then clamps it.

:saveState()

Snapshots target, theta, phi and radius for later restoration.

:reset()

Restores the state captured by saveState, or does nothing if none was saved.

:dispose()

Disables the controls and clears any in-progress drag.

Differences from three.js

  • No DOM element to attach to — the host application must forward LÖVE's mousepressed/mousereleased/mousemoved/wheelmoved callbacks explicitly.
  • update(dt) takes a delta-time argument, which three.js's version does not; it exists to drive frame-rate-independent damping.
  • No keyboard pan, touch gestures, auto-rotate, or screen-space-panning toggle.

OrbitControls

Вращает (orbit), приближает (dolly) и панорамирует камеру вокруг точки target, с теми же привязками мыши, что и OrbitControls в three.js: перетаскивание левой кнопкой вращает, правой — панорамирует, колесо приближает. В отличие от FlyControls, этот контроллер полностью владеет позицией камеры — он вычисляет её из target плюс сферическое смещение на каждом обновлении, так что прямая запись в camera.position будет перезаписана на следующем кадре. Вместо этого перемещайте target.

Constructor

OrbitControls.new(camera, params)

Инициализирует свои сферические координаты (radius/theta/phi) исходя из текущего положения камеры относительно target, так что создание контроллера не телепортирует камеру. params — необязательная таблица, переопределяющая любое из свойств ниже. Перед возвратом один раз вызывает update(0).

Methods

:update(dt)

Плавно приближает (если enableDamping) или мгновенно устанавливает текущие сферические координаты к целевым, затем перепозиционирует камеру от target плюс сферическое смещение и вызывает lookAt(target). В отличие от версии three.js, принимает dt, специально для управления демпфированием.

:mousepressed(x, y, button)

Запоминает режим перетаскивания: левая кнопка (1) начинает вращение, правая (2) — панорамирование.

:mousereleased(x, y, button)

Сбрасывает текущий режим перетаскивания.

:mousemoved(x, y, dx, dy)

Применяет дельту перетаскивания согласно текущему режиму (при отсутствии переданного mousepressed читает love.mouse.isDown напрямую в реальном времени): вращение изменяет theta/phi, панорамирование сдвигает target вдоль базиса right/up камеры, масштабированного расстоянием.

:wheelmoved(dy)

Масштабирует целевой radius на zoomSpeed или обратную величину в зависимости от направления прокрутки, затем ограничивает его.

:saveState()

Сохраняет снимок target, theta, phi и radius для последующего восстановления.

:reset()

Восстанавливает состояние, сохранённое через saveState, либо ничего не делает, если ничего не было сохранено.

:dispose()

Отключает контроллер и очищает любое незавершённое перетаскивание.

Differences from three.js

  • Нет DOM-элемента для подключения — хост-приложение должно явно пересылать колбэки LÖVE mousepressed/mousereleased/mousemoved/wheelmoved.
  • update(dt) принимает аргумент delta-времени, чего нет в версии three.js; это нужно для демпфирования, не зависящего от частоты кадров.
  • Нет панорамирования клавиатурой, сенсорных жестов, авто-вращения или переключателя screen-space-panning.
