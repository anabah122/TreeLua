Quaternion

Represents a rotation. Written against the three.js Quaternion API from the start, so every method mutates self and returns it, letting calls chain.

Constructor

Quaternion( x, y, z, w )

Default is the identity rotation (0, 0, 0, 1).

Properties

PropertyTypeDefaultDescription
xnumber0
ynumber0
znumber0
wnumber1

Methods

.set( x, y, z, w )

Sets the four components. Returns self.

.clone()

Returns a new Quaternion with the same components.

.copy( q )

Copies the components of q into this quaternion. Returns self.

.identity()

Resets this quaternion to (0, 0, 0, 1). Returns self.

.equals( q )

Returns true if this quaternion and q have identical components.

.length()

Returns the Euclidean length of this quaternion.

.lengthSq()

Returns the squared length.

.normalize()

Normalizes this quaternion in place. Resets to identity if length is zero. Returns self.

.conjugate()

Negates the x, y, z components in place, leaving w unchanged. Returns self.

.invert()

Inverts this quaternion in place. Implemented as the conjugate, which is exact for the unit quaternions this engine produces.

.dot( q )

Returns the dot product of this quaternion and q.

.setFromAxisAngle( axis, angle )

Sets this quaternion to represent a rotation of angle radians about axis. Returns self.

.setFromEuler( euler )

Sets this quaternion from an Euler. Returns self.

.setFromRotationMatrix( m )

Extracts the rotation component of matrix m (ignoring scale) into this quaternion. Delegates to Matrix4:decompose. Returns self.

.setFromUnitVectors( from, to )

Sets this quaternion to the shortest rotation taking unit vector from onto unit vector to. Returns self.

.multiplyQuaternions( a, b )

Sets this quaternion to a * b. Returns self.

.multiply( q )

Sets this quaternion to this * q. Returns self.

.premultiply( q )

Sets this quaternion to q * this. Returns self.

.slerp( q, t )

Spherically interpolates this quaternion toward q by t, in place. Falls back to a normalized linear interpolation when the two quaternions are nearly parallel. Returns self.

.slerpQuaternions( a, b, t )

Sets this quaternion to the spherical interpolation of a and b by t. Returns self.

.angleTo( q )

Returns the angle in radians between this quaternion's rotation and q's.

.rotateTowards( q, step )

Rotates this quaternion toward q by at most step radians. Returns self.

.toArray()

Returns {x, y, z, w}.

.fromArray( array, offset )

Sets this quaternion's components from array starting at offset. Returns self.

Differences from three.js

  • .setFromEuler fully supports only the XYZ and YXZ orders plus the four other three.js orders (ZXY, ZYX, YZX, XZY) via explicit branches; any unrecognized order falls back to XYZ rather than the three.js behavior of supporting all six unconditionally through a single generic formula.
  • .invert() is implemented as .conjugate(). This is only exact for unit-length quaternions, which is all this engine constructs — three.js's invert() also conjugates, but documents it as valid generally because three.js normalizes internally where needed.

Quaternion

Представляет вращение. С самого начала написан по API Quaternion из three.js, поэтому каждый метод изменяет self и возвращает его, позволяя вызовы в цепочку.

Constructor

Quaternion( x, y, z, w )

По умолчанию — единичное вращение (0, 0, 0, 1).

Properties

СвойствоТипПо умолчаниюОписание
xnumber0
ynumber0
znumber0
wnumber1

Methods

.set( x, y, z, w )

Устанавливает четыре компонента. Возвращает self.

.clone()

Возвращает новый Quaternion с теми же компонентами.

.copy( q )

Копирует компоненты q в этот кватернион. Возвращает self.

.identity()

Сбрасывает этот кватернион к (0, 0, 0, 1). Возвращает self.

.equals( q )

Возвращает true, если этот кватернион и q имеют идентичные компоненты.

.length()

Возвращает евклидову длину этого кватерниона.

.lengthSq()

Возвращает квадрат длины.

.normalize()

Нормализует этот кватернион на месте. Сбрасывает к единичному, если длина равна нулю. Возвращает self.

.conjugate()

Меняет знак компонентов x, y, z на месте, оставляя w без изменений. Возвращает self.

.invert()

Обращает этот кватернион на месте. Реализован через сопряжение, что точно для единичных кватернионов, которые только и производит этот движок.

.dot( q )

Возвращает скалярное произведение этого кватерниона и q.

.setFromAxisAngle( axis, angle )

Устанавливает этот кватернион как представление вращения на angle радиан вокруг axis. Возвращает self.

.setFromEuler( euler )

Устанавливает этот кватернион из Euler. Возвращает self.

.setFromRotationMatrix( m )

Извлекает компонент вращения матрицы m (игнорируя масштаб) в этот кватернион. Делегирует в Matrix4:decompose. Возвращает self.

.setFromUnitVectors( from, to )

Устанавливает этот кватернион как кратчайшее вращение, переводящее единичный вектор from в единичный вектор to. Возвращает self.

.multiplyQuaternions( a, b )

Устанавливает этот кватернион в a * b. Возвращает self.

.multiply( q )

Устанавливает этот кватернион в this * q. Возвращает self.

.premultiply( q )

Устанавливает этот кватернион в q * this. Возвращает self.

.slerp( q, t )

Сферически интерполирует этот кватернион к q по t, на месте. Переходит на нормализованную линейную интерполяцию, когда два кватерниона почти параллельны. Возвращает self.

.slerpQuaternions( a, b, t )

Устанавливает этот кватернион как сферическую интерполяцию a и b по t. Возвращает self.

.angleTo( q )

Возвращает угол в радианах между вращением этого кватерниона и вращением q.

.rotateTowards( q, step )

Поворачивает этот кватернион к q не более чем на step радиан. Возвращает self.

.toArray()

Возвращает {x, y, z, w}.

.fromArray( array, offset )

Устанавливает компоненты этого кватерниона из array, начиная с offset. Возвращает self.

Differences from three.js

  • .setFromEuler полностью поддерживает порядки XYZ и YXZ, а также четыре остальных порядка three.js (ZXY, ZYX, YZX, XZY) через явные ветки; любой нераспознанный порядок откатывается к XYZ, а не поддерживает все шесть безусловно через единую общую формулу, как в three.js.
  • .invert() реализован как .conjugate(). Это точно только для кватернионов единичной длины, а движок конструирует только такие — invert() в three.js тоже сопрягает, но документирует это как общий случай, поскольку three.js нормализует внутренне там, где нужно.
