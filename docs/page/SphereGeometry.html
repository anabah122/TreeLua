TreeLua / Geometries

SphereGeometry

A UV sphere: rings of latitude subdivided along longitude. The phi/theta start/length arguments allow a partial sphere — a dome or a wedge — from the same generator, matching three.js.

Constructor

SphereGeometry(radius, widthSegments, heightSegments, phiStart, phiLength, thetaStart, thetaLength)

radius defaults to 1. widthSegments defaults to 32 (minimum 3), heightSegments defaults to 16 (minimum 2). phiStart/thetaStart default to 0; phiLength defaults to 2π; thetaLength defaults to π.

Properties

PropertyTypeDefaultDescription
parameterstable—{ radius, widthSegments, heightSegments, phiStart, phiLength, thetaStart, thetaLength } as resolved by the constructor.

Methods

No methods beyond the constructor and what BufferGeometry provides.

Differences from three.js

  • Built through the shared three/geometries/build.lua helper, which forces convex-about-origin outward winding on every triangle. A full sphere is convex, so this is transparent; degenerate pole triangles are skipped by the generator itself rather than by build().

TreeLua / Geometries

SphereGeometry

UV-сфера: кольца широты, подразделённые по долготе. Аргументы phi/theta start/length позволяют получить частичную сферу — купол или клин — из того же генератора, как в three.js.

Constructor

SphereGeometry(radius, widthSegments, heightSegments, phiStart, phiLength, thetaStart, thetaLength)

radius по умолчанию 1. widthSegments по умолчанию 32 (минимум 3), heightSegments по умолчанию 16 (минимум 2). phiStart/thetaStart по умолчанию 0; phiLength по умолчанию 2π; thetaLength по умолчанию π.

Properties

СвойствоТипПо умолчаниюОписание
parameterstable—{ radius, widthSegments, heightSegments, phiStart, phiLength, thetaStart, thetaLength }, как разрешено конструктором.

Methods

Нет методов, кроме конструктора и того, что предоставляет BufferGeometry.

Differences from three.js

  • Строится через общий хелпер three/geometries/build.lua, который принудительно задаёт выпуклый (относительно начала координат) внешний winding для каждого треугольника. Полная сфера выпукла, поэтому это не влияет на результат; вырожденные треугольники на полюсах пропускаются самим генератором, а не build().

Source: three/geometries/SphereGeometry.lua
