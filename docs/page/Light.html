TreeLua / Lights

Light

Extends Object3D, inherits its API. Lights sit in the scene graph and inherit a transform, which matters for DirectionalLight and SpotLight, whose direction is derived from where they sit relative to a target rather than stored as a vector.

Constructor

Light(color, intensity)

color defaults to 0xffffff, intensity to 1.

Properties

PropertyTypeDefaultDescription
colorColor0xffffff
intensitynumber1

Methods

.isLight()

Returns true.

.effectiveColor(target)

Colour scaled by intensity — what a shader uniform wants. No direct three.js equivalent (three.js's WebGLLights does the equivalent scaling internally, not as a public method).

.copy(source, recursive)

.dispose()

No-op, kept for API compatibility — there is nothing GPU-side to release.

Differences from three.js

  • The bundled shader samples exactly one DirectionalLight plus one ambient term. A scene may hold more lights of any kind, but only that pair reaches the shader — see DirectionalLight and PointLight for the details.
  • .effectiveColor(target) is a TreeLua-only facade with no three.js equivalent.

TreeLua / Lights

Light

Наследует Object3D, наследует её API. Источники света находятся в графе сцены и наследуют трансформ, что важно для DirectionalLight и SpotLight, чьё направление выводится из положения относительно цели, а не хранится как вектор.

Constructor

Light(color, intensity)

color по умолчанию 0xffffff, intensity — 1.

Properties

СвойствоТипПо умолчаниюОписание
colorColor0xffffff
intensitynumber1

Methods

.isLight()

Возвращает true.

.effectiveColor(target)

Цвет, умноженный на интенсивность — то, что нужно uniform шейдера. Нет прямого аналога в three.js (WebGLLights в three.js делает эквивалентное масштабирование внутренне, а не как публичный метод).

.copy(source, recursive)

.dispose()

Пустая операция, сохранена ради совместимости API — освобождать на стороне GPU нечего.

Differences from three.js

  • Встроенный шейдер сэмплирует ровно один DirectionalLight плюс один ambient-член. Сцена может содержать больше источников света любого типа, но до шейдера доходит только эта пара — подробности смотрите в DirectionalLight и PointLight.
  • .effectiveColor(target) — фасад, существующий только в TreeLua, без аналога в three.js.
