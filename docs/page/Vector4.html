Vector4

A 4-component vector, used for homogeneous coordinates and other quadruples of numbers.

Constructor

Vector4( x, y, z, w )

x, y, z, w — the component values. Default 0 for each.

Properties

PropertyTypeDefaultDescription
xnumber0The x component.
ynumber0The y component.
znumber0The z component.
wnumber0The w component.

Methods

.clone()

Returns a new Vector4 with the same x, y, z, w values.

.equals( v )

Returns true if this vector and v have identical components.

.add( v )

Returns a new vector: this + v. Also accepts a scalar, added to every component. Does not modify self.

.sub( v )

Returns a new vector: this - v (or scalar). Does not modify self.

.mul( v )

Returns a new vector: component-wise this * v (or scalar). Does not modify self.

.div( v )

Returns a new vector: component-wise this / v (or scalar). Does not modify self.

.magnitude()

Returns the Euclidean length of this vector.

.distanceTo( v )

Returns the Euclidean distance between this vector and v.

.dot( v )

Returns the dot product of this vector and v.

.normalize()

Returns a new unit-length vector in the same direction. If length is zero, returns a zero vector.

.clamp( min, max )

Returns a new vector with each component clamped between min and max (both may be scalars or vectors).

.clampMagnitude( maxLength )

Returns a new vector scaled down to maxLength if its length exceeds it.

.abs()

Returns a new vector with each component's absolute value.

.frac()

Returns a new vector with the fractional part of each component.

.project( dir )

Returns a new vector: the projection of this vector onto dir.

.min( v )

Returns a new vector with the component-wise minimum of this and v (or scalar).

.max( v )

Returns a new vector with the component-wise maximum of this and v (or scalar).

.floor()

Returns a new vector with each component floored.

.ceil()

Returns a new vector with each component ceiled.

.round()

Returns a new vector with each component rounded to the nearest integer.

.lerp( target, t )

Returns a new vector linearly interpolated between this and target by t.

.angle( v )

Returns the angle in radians between this vector and v.

.approach( target, amount )

Returns a new vector moved from this toward target by up to amount; reaches target exactly if within amount.

Differences from three.js

  • All arithmetic methods (add, sub, mul, div, normalize, clamp, min, max, floor, ceil, round, lerp) are immutable here — they return a new Vector4 and leave self unchanged, unlike three.js where these mutate self and return it. Vector4 does not have the mutating *Self/setX-style three.js-compatible layer that Vector3 has; only the original immutable API is implemented.
  • No set, copy, setFromMatrixPosition, or applyMatrix4 — Vector4 is used purely as a value type, not wired into the matrix/quaternion transform pipeline the way Vector3 is.

Vector4

Четырёхкомпонентный вектор, используется для однородных координат и других четвёрок чисел.

Constructor

Vector4( x, y, z, w )

x, y, z, w — значения компонентов. По умолчанию 0 для каждого.

Properties

СвойствоТипПо умолчаниюОписание
xnumber0Компонент x.
ynumber0Компонент y.
znumber0Компонент z.
wnumber0Компонент w.

Methods

.clone()

Возвращает новый Vector4 с теми же значениями x, y, z, w.

.equals( v )

Возвращает true, если этот вектор и v имеют идентичные компоненты.

.add( v )

Возвращает новый вектор: this + v. Также принимает скаляр, который добавляется к каждому компоненту. Не изменяет self.

.sub( v )

Возвращает новый вектор: this - v (или скаляр). Не изменяет self.

.mul( v )

Возвращает новый вектор: покомпонентное this * v (или скаляр). Не изменяет self.

.div( v )

Возвращает новый вектор: покомпонентное this / v (или скаляр). Не изменяет self.

.magnitude()

Возвращает евклидову длину этого вектора.

.distanceTo( v )

Возвращает евклидово расстояние между этим вектором и v.

.dot( v )

Возвращает скалярное произведение этого вектора и v.

.normalize()

Возвращает новый вектор единичной длины в том же направлении. Если длина равна нулю, возвращает нулевой вектор.

.clamp( min, max )

Возвращает новый вектор с каждым компонентом, ограниченным между min и max (оба могут быть скалярами или векторами).

.clampMagnitude( maxLength )

Возвращает новый вектор, уменьшенный до maxLength, если его длина превышает это значение.

.abs()

Возвращает новый вектор с абсолютным значением каждого компонента.

.frac()

Возвращает новый вектор с дробной частью каждого компонента.

.project( dir )

Возвращает новый вектор: проекцию этого вектора на dir.

.min( v )

Возвращает новый вектор с покомпонентным минимумом this и v (или скаляра).

.max( v )

Возвращает новый вектор с покомпонентным максимумом this и v (или скаляра).

.floor()

Возвращает новый вектор с каждым компонентом, округлённым вниз.

.ceil()

Возвращает новый вектор с каждым компонентом, округлённым вверх.

.round()

Возвращает новый вектор с каждым компонентом, округлённым до ближайшего целого.

.lerp( target, t )

Возвращает новый вектор, линейно интерполированный между this и target по t.

.angle( v )

Возвращает угол в радианах между этим вектором и v.

.approach( target, amount )

Возвращает новый вектор, сдвинутый от this к target не более чем на amount; достигает target точно, если расстояние в пределах amount.

Differences from three.js

  • Все арифметические методы (add, sub, mul, div, normalize, clamp, min, max, floor, ceil, round, lerp) здесь иммутабельны — они возвращают новый Vector4 и не изменяют self, в отличие от three.js, где эти методы мутируют self и возвращают его. У Vector4 нет мутирующего слоя *Self/setX-стиля, совместимого с three.js, который есть у Vector3 — реализован только исходный иммутабельный API.
  • Нет set, copy, setFromMatrixPosition или applyMatrix4 — Vector4 используется исключительно как тип значения, а не встроен в конвейер трансформации матриц/кватернионов, как Vector3.
