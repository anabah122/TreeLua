TreeLua / Animation

PoseAccumulator

TreeLua-specific internal helper with no direct equivalent in three.js. It exists to let AnimationMixer combine several simultaneously-playing AnimationActions into a single per-bone pose each frame: translation and scale are accumulated as weighted linear averages, and rotation is accumulated via successive quaternion slerp with hemisphere selection so opposite-signed quaternions don't fight each other. It is what makes the mixer's default blending = true behavior possible.

Constructor

PoseAccumulator.new()

Creates an empty accumulator with no accumulated bone entries.

Properties

PropertyTypeDefaultDescription
entriestable{}Per-bone accumulated state keyed by target name, each holding running weighted translation/scale sums and the running slerped rotation plus total weight seen so far.

Methods

:reset()

Clears all accumulated entries so the accumulator can be reused for the next frame.

:add(targetName, type, value, weight)

Folds one action's sampled value for a bone/property into the running result: translation and scale are weighted-summed, rotation is combined into the running quaternion via slerp (choosing the shorter-arc hemisphere against the accumulated-so-far rotation) weighted by this call's proportion of total weight seen for that target.

:apply(root)

Writes the final accumulated translation/rotation/scale for every entry onto the matching named node under root.

TreeLua / Animation

PoseAccumulator

Внутренний вспомогательный класс, специфичный для TreeLua, без прямого аналога в three.js. Он существует, чтобы позволить AnimationMixer объединять несколько одновременно проигрывающихся AnimationAction в единую позу по костям на каждом кадре: translation и scale накапливаются как взвешенные линейные средние, а rotation накапливается через последовательный кватернионный slerp с выбором полушария, чтобы кватернионы с противоположным знаком не конфликтовали друг с другом. Именно это делает возможным поведение миксера по умолчанию при blending = true.

Constructor

PoseAccumulator.new()

Создаёт пустой аккумулятор без накопленных записей по костям.

Properties

СвойствоТипПо умолчаниюОписание
entriestable{}Накопленное состояние по каждой кости, индексированное по имени цели, содержащее текущие взвешенные суммы translation/scale, текущий слерпленный rotation и суммарный вес, учтённый на данный момент.

Methods

:reset()

Очищает все накопленные записи, чтобы аккумулятор можно было переиспользовать на следующем кадре.

:add(targetName, type, value, weight)

Добавляет сэмплированное значение одного экшена для кости/свойства в текущий результат: translation и scale суммируются с учётом веса, rotation объединяется в текущий кватернион через slerp (выбирая более короткую дугу относительно уже накопленного вращения) с весом, пропорциональным доле этого вызова в суммарном весе, учтённом для этой цели.

:apply(root)

Записывает итоговые накопленные translation/rotation/scale для каждой записи в соответствующий узел с таким же именем внутри root.
