TreeLua / Animation

AnimationClip

A reusable set of keyframe tracks representing an animation. A clip groups tracks (per-property keyframe data) under a name and a total duration, and is played back through an AnimationAction on an AnimationMixer.

Constructor

AnimationClip.new(name, duration, tracks)

Creates a clip from a name, a duration in seconds and an array of tracks. Each track is a plain table describing a single animated property.

Properties

PropertyTypeDefaultDescription
namestring—Clip identifier, used to look it up by name.
durationnumber—Clip length in seconds.
trackstable[]—Array of keyframe tracks. Each track has targetName (node/bone name), type ("translation", "rotation" or "scale"), times (array of keyframe timestamps) and values (flat array of vector/quaternion components, one entry per keyframe).

Methods

:getTrackForBone(name, type)

Returns the track matching a given target/bone name and property type ("translation", "rotation" or "scale"), or nil if the clip has no such track.

Differences from three.js

  • Tracks are plain Lua tables with targetName/type/times/values fields rather than KeyframeTrack subclass instances (VectorKeyframeTrack, QuaternionKeyframeTrack, etc.).
  • No CLIP_STAINS serialization helpers (toJSON, parse, CreateFromMorphTargetSequence, ...) — clips are constructed directly from loader data.

TreeLua / Animation

AnimationClip

Переиспользуемый набор ключевых дорожек (keyframe tracks), представляющий анимацию. Клип группирует tracks (данные ключевых кадров по каждому свойству) под общим name и общей duration, и воспроизводится через AnimationAction на AnimationMixer.

Constructor

AnimationClip.new(name, duration, tracks)

Создаёт клип из имени, длительности в секундах и массива дорожек. Каждая дорожка — обычная таблица, описывающая одно анимируемое свойство.

Properties

СвойствоТипПо умолчаниюОписание
namestring—Идентификатор клипа, используется для поиска по имени.
durationnumber—Длительность клипа в секундах.
trackstable[]—Массив ключевых дорожек. Каждая дорожка содержит targetName (имя узла/кости), type ("translation", "rotation" или "scale"), times (массив временных меток ключевых кадров) и values (плоский массив компонентов вектора/кватерниона, по одной записи на ключевой кадр).

Methods

:getTrackForBone(name, type)

Возвращает дорожку, соответствующую заданному имени цели/кости и типу свойства ("translation", "rotation" или "scale"), либо nil, если у клипа нет такой дорожки.

Differences from three.js

  • Дорожки — обычные Lua-таблицы с полями targetName/type/times/values, а не экземпляры подклассов KeyframeTrack (VectorKeyframeTrack, QuaternionKeyframeTrack и т.д.).
  • Нет вспомогательных средств сериализации CLIP_STAINS (toJSON, parse, CreateFromMorphTargetSequence, ...) — клипы создаются напрямую из данных загрузчика.
