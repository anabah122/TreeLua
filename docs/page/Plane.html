TreeLua / Math

Plane

An infinite plane in Hessian normal form: the set of points where dot(normal, point) + constant == 0. constant is the signed distance from the origin to the plane along the negated normal, matching three.js.

Constructor

Plane( normal, constant )

normal — a Vector3, cloned in, defaults to (1, 0, 0). constant defaults to 0.

Properties

PropertyTypeDefaultDescription
normalVector3(1,0,0)
constantnumber0

Methods

.isPlane()

Returns true. Type-check facade.

.set( normal, constant )

Sets normal (copied) and constant. Returns self.

.setComponents( x, y, z, w )

Sets normal to (x, y, z) and constant to w. Returns self.

.clone()

Returns a new Plane with the same normal and constant.

.copy( plane )

Copies plane's normal and constant into this plane. Returns self.

.setFromNormalAndCoplanarPoint( normal, point )

Sets this plane from a normal and a point known to lie on it. Returns self.

.setFromCoplanarPoints( a, b, c )

Sets this plane to pass through three coplanar points. Returns self.

.normalizeSelf()

Scales the plane equation so the normal is unit length, which is what makes distanceToPoint return a true distance rather than a proportional value. Returns self.

.negate()

Flips the plane to face the opposite direction, in place. Returns self.

.distanceToPoint( point )

Returns the signed distance from point to this plane.

.distanceToSphere( sphere )

Returns the signed distance from sphere's surface to this plane.

.projectPoint( point, target )

Writes the projection of point onto this plane into target and returns it.

.coplanarPoint( target )

Writes an arbitrary point lying on this plane into target and returns it.

.translate( offset )

Moves this plane by offset, in place. Returns self.

.equals( plane )

Returns true if this plane and plane have equal normal and constant.

Differences from three.js

  • The mutating normalize method is named .normalizeSelf() rather than three.js's .normalize(), for consistency with the rest of TreeLua's math classes where a bare normalize often means "return a new value" — here there is only the mutating form.

TreeLua / Math

Plane

Бесконечная плоскость в нормальной форме Гессе: множество точек, где dot(normal, point) + constant == 0. constant — знаковое расстояние от начала координат до плоскости вдоль отрицательной нормали, как в three.js.

Constructor

Plane( normal, constant )

normal — Vector3, клонируется при передаче, по умолчанию (1, 0, 0). constant по умолчанию 0.

Properties

СвойствоТипПо умолчаниюОписание
normalVector3(1,0,0)
constantnumber0

Methods

.isPlane()

Возвращает true. Фасад проверки типа.

.set( normal, constant )

Устанавливает normal (копируется) и constant. Возвращает self.

.setComponents( x, y, z, w )

Устанавливает normal в (x, y, z) и constant в w. Возвращает self.

.clone()

Возвращает новую Plane с той же нормалью и константой.

.copy( plane )

Копирует normal и constant из plane в эту плоскость. Возвращает self.

.setFromNormalAndCoplanarPoint( normal, point )

Устанавливает эту плоскость по нормали и точке, заведомо лежащей на ней. Возвращает self.

.setFromCoplanarPoints( a, b, c )

Устанавливает эту плоскость так, чтобы она проходила через три компланарные точки. Возвращает self.

.normalizeSelf()

Масштабирует уравнение плоскости так, чтобы нормаль имела единичную длину, благодаря чему distanceToPoint возвращает истинное расстояние, а не пропорциональное значение. Возвращает self.

.negate()

Разворачивает плоскость в противоположную сторону, на месте. Возвращает self.

.distanceToPoint( point )

Возвращает знаковое расстояние от point до этой плоскости.

.distanceToSphere( sphere )

Возвращает знаковое расстояние от поверхности sphere до этой плоскости.

.projectPoint( point, target )

Записывает проекцию point на эту плоскость в target и возвращает его.

.coplanarPoint( target )

Записывает произвольную точку, лежащую на этой плоскости, в target и возвращает его.

.translate( offset )

Сдвигает эту плоскость на offset, на месте. Возвращает self.

.equals( plane )

Возвращает true, если у этой плоскости и plane равны normal и constant.

Differences from three.js

  • Изменяющий метод нормализации называется .normalizeSelf(), а не .normalize(), как в three.js, для согласованности с остальными математическими классами TreeLua, где голый normalize часто означает "вернуть новое значение" — здесь есть только изменяющая форма.
